## LY.TRAVEL.HJC.54 行人·父动卦中当有鱼书之寄：占书信，卦中父母爻发动，主有音信寄来

**规则(整理,不是原文)**:占书信，卦里有父母爻发动，主有音信寄来。

**Rule (our summary, not the source text):** In divining for a letter, if a Resource line moves in the hexagram a letter will be sent.

**《黄金策·行人》原文** — 《卜筮正宗》第 3534 行 · *Huangjin Ce (The Golden Strategy), "Absent travellers", base text; Bushi Zhengzong, line 3534*

| 原文 | 译文 | English |
| --- | --- | --- |
| 父动卦中， | 父母爻在卦中发动， | If the Resource line moves in the hexagram, |
| 当有鱼书之寄 | 应当有书信寄来 | a letter should be sent |

**王洪绪注(《卜筮正宗》)** — 《卜筮正宗》第 3534 行 · *Wang Hongxu's commentary (Bushi Zhengzong); Bushi Zhengzong, line 3534*

| 原文 | 译文 | English |
| --- | --- | --- |
| 凡占书信，卦有父母爻动，主有音信寄来。 | 凡是占书信，卦里有父母爻发动，主有音信寄来。 | In divining for a letter, if a Resource line moves in the hexagram a letter will be sent. |

> **按**:「鱼书」是书信的雅称，出自旧时鲤鱼传书的说法。
>
> **Note:** "Fish letter" is an elegant name for a letter, from the old tale of a letter carried in a carp.

他本同文、异文(程序比对,只比本文):

- 《黄金策》:同文 第 2933 行:当有鱼书之寄

## LY.TRAVEL.HJC.55 行人·财兴世上应无信之来：单占书信以父母爻为用神，世爻持财发动则克父母，所以没有书信到来

**规则(整理,不是原文)**:单独占书信，以父母爻为用神；如果世爻带着财爻发动，就克了父母，所以没有书信到来。

**Rule (our summary, not the source text):** In divining for a letter alone, the Resource line is the Subject; if the Self carries a moving Wealth line it controls Resource, so no letter comes.

**《黄金策·行人》原文** — 《卜筮正宗》第 3536 行 · *Huangjin Ce (The Golden Strategy), "Absent travellers", base text; Bushi Zhengzong, line 3536*

| 原文 | 译文 | English |
| --- | --- | --- |
| 财兴世上， | 财爻在世位上兴旺发动， | If Wealth flourishes and moves on the Self, |
| 应无信之来 | 应该没有书信到来 | no letter should come |

**王洪绪注(《卜筮正宗》)** — 《卜筮正宗》第 3536 行 · *Wang Hongxu's commentary (Bushi Zhengzong); Bushi Zhengzong, line 3536*

| 原文 | 译文 | English |
| --- | --- | --- |
| 独占书信，以父母爻为用神，若世持财动则克父矣，故无雁信之来也。 | 单独占书信，以父母爻为用神，如果世爻带着财爻发动就克了父母，所以没有书信到来。 | In divining for a letter alone, the Resource line is the Subject; if the Self carries a moving Wealth line it controls Resource, so no letter comes. |

## LY.TRAVEL.ZS.31 行人章·书中例，占差家人取书得否、何日回：人今日酉时必到，书得不到——父母化回头之克；世爻化卯鬼人不到必有忧，酉时冲去卯木则无忧

**规则(整理,不是原文)**:动爻化出克它的爻最凶；文书以父母爻为用神，化出回头克就得不到书。书中例：辰月丙申日占派家人去取书能不能取到、哪天回来，得渐卦变剥卦：仆人今天酉时必到，书得不到。问怎么知道的，我说：巳火父母化出回头之克，所以得不到书；甲子持世化出卯木官鬼，人不到必有忧虑，今天酉时冲去卯木，就没有忧了；果然酉时到了，而书没有取到。

**Rule (our summary, not the source text):** A movement that changes into a controlling line is the most ill; a document is read from the Resource line, and if it changes into a turning-back control the document is not obtained. Worked example: in the Chen month, on a Bingshen day, a man divined whether a household servant sent to fetch a book would get it and on what day he would return, and got Jian changing to Bo: the servant will surely arrive this day in the You hour, but the book will not be had. Asked how I knew, I said: the Resource Si-fire changes into a turning-back control, so the book is not obtained; Jiazi holds the Self and changes into the Pressure Mao-wood, so if he did not arrive there would surely be worry, but this day in the You hour the clash removes the Mao-wood, so there is no worry. He did arrive in the You hour, and the book was not got.
