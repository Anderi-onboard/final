# 六爻 · 官非 · 文书

*Liu Yao (six-line coin divination) · Lawsuits and disputes · Papers and records*

## LY.LAWSUIT.HJC.11 词讼·父为案卷文书伏须未就：卦里没有父母爻，文书还没有写成；带刑临败病必有破绽，化财也一样；化兄会被驳回，月建作合，上司必定调卷，有冲就都不准许

**规则(整理,不是原文)**:父母爻是案卷文书，伏藏着就一定还没有办成。卦里没有父母，文书未就；带刑、临败地和病地，必多破绽，化财也一样；化兄弟会被驳回，月建来合，上司必定调案卷，有冲的都不依允。

**Rule (our summary, not the source text):** The Resource line is the case file and papers, and if it is hidden they are surely not yet done. If the hexagram has no Resource, the papers are not done; if it carries punishment and sits on a place of decay or illness, there are many flaws, and likewise if it changes into Wealth; changing into Peer, it is rejected; if the Month combines it, the superior office will surely call up the file; if it is clashed, none of it is approved.
