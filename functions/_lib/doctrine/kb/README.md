# 古籍断法库

古书里的判断规则，按问题分：先分问题域（求财、婚姻、疾病……），再分主题（求财下面分「有无」「难易」「应期」「买卖」等 14 个）。
每条规则是一个判断点，带三样东西：

- **原文**：从 `../books/` 里逐字抄出，程序核对过，注明哪本书第几行；
- **译文**：现代汉语；
- **English**：英文。

三样逐句对齐，一行原文对一行译文、一行英文。几家说法不同的，标「打架」，各家原文都列出来。

## 一条规则长什么样

```json
{
  "id": "LY.WEALTH.HJC.08",
  "topic": "应期",
  "title": "日伤妻位，财虽旺而当日应无",
  "rule": { "yi": "……整理的规则……", "en": "…" },
  "quotes": [
    { "by": "经", "book": "卜筮大全",
      "zh": ["日伤妻位，", "财虽旺，而当日应无。"],
      "yi": ["日辰克伤财爻，", "财即使旺，当天也得不到。"],
      "en": ["When the Day harms the Wealth line,", "even a thriving Wealth brings nothing that day."] },
    { "by": "旧注", "book": "卜筮大全", "zh": […], "yi": […], "en": […] }
  ],
  "dispute": { "yi": "……几家怎么不同……", "en": "…" }
}
```

- `id`：术数代号.问题域代号.书的代号.序号。发出去就不改。
- `quotes` 第一段必须是这部书的本文（`by: 经`），后面是注和别家的话。`zh`、`yi`、`en` 三个数组一样长，第几句对第几句。
- `rule` 是本库的归纳，**不是原文**；页面上都标着「整理」。
- 文件开头的 `ranges` 写这一章在每本书里的行号范围；某一段引自别的章，就在那一段上单写 `range`（本文的 `by: 经` 那一段还要单写 `chapter` / `chapter_en`，否则标签会沿用规则所属的那一章）。

## 程序核对什么

每次跑 `build.mjs` 和 `npm test` 都核，一处不对就报红，不生成：

1. **原文逐字**：每段原文去掉空白（换行、全角空格）后，必须在它标的那本书里原样出现，标点也算；几句连起来也必须在书里连着。
2. **在对的章里**：出现的位置必须落在这一章的行号范围里。同一句在书里别处也有，不算数。
3. **三栏对齐**：原文、译文、英文句数一样，不许空；英文栏不许有汉字；译文不许照抄原文。
4. **英文术语统一**：原文出现「妻财」「财爻」，英文那一句必须有 Wealth；「子孙」→ Output，「兄弟」→ Peer，「官鬼」→ Pressure，「父母」→ Resource，「世爻」→ Self，「应爻」→ Other，「用神」→ Subject，「月建」→ Month，「日辰」→ Day，「旬空」「空亡」→ Void，等等（全表见 `terms.json` 的 `check`）。某一段里这个词是字面意思（比如「父母」指爹娘），在那段 quote 上写 `"literal": ["父母"]`，只豁免那一段。
5. `tests/kb-quotes.mjs` 另外把十种错误（改一个字、少一个标点、引错书、句子不在这一章、三栏不齐、英文漏术语……）逐一植进一份副本，每一种都必须被抓到。

**他本同文、异文**是程序自动比出来的：每句本文拿到同一门的其他书里找最像的一段，完全相同标「同文」，相似度 0.75 以上标「异文」并写出那本的字句。只比本文，不比注。

## 不收什么

- 书里今人加的按语：《增删卜易》的「[乾按]」「[提要]」「[居士按]」，《断易天机》的「[注释]」「[译文]」「虎易注」。这些是今人写的，有版权，也不是古籍。
- 书中的卦例只收判断那几句和卦的出处（月日、卦名），不收排盘图。

## 行号是哪一份的

行号是 `../books/` 下那份整理本的行号，**不是原刻本的页码**。六爻那七本是 owner 合集还原校对的（见 `../books/README.md`），其余是网上转录本。
要把一句话录进判据库（`../BOOK-DB.md`），仍以影印本那一页为准。
