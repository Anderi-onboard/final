# 世静而空亡、世动化退神，终成空：动而空的等实空之月日必成，静而空终不成；世动化进必成、化退难成；应爻同断

六爻 · 婚姻 · 成否 · 出处 [[增删卜易]]

> [!abstract] 规则(整理,不是原文)
> 世爻静而落空亡，或者动了变成退神，终究要失望。世爻动而落空的，到填实空亡的月份、日子一定成；静而落空的，终究不成。世爻动：化成进神一定成，化成退神难成。应爻静而空、破，或者化成退神，也照这个推。
>
> *Rule (our summary):* A Self line that is still and Void, or that moves and changes into a Retreating spirit, ends in disappointment. If it moves and is Void, it succeeds in the month or day that fills the Void; if it is still and Void, it never succeeds. If the Self line moves, changing into an Advancing spirit it surely succeeds, changing into a Retreating spirit it is hard to accomplish. A still Other line that is Void or broken, or that changes into a Retreating spirit, is judged the same way.
