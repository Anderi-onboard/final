# 倩媒同于托人，用应爻：冲则不能合、克世则有私；应爻空则不力、破则不专，旺相为我则重、休囚助己则轻，冲世误事、克世存欲，合处逢冲成而复解

六爻 · 婚姻 · 媒妁 · 出处 [[易冒]]

> [!abstract] 规则(整理,不是原文)
> 请媒人和托人办事是一样的，用应爻作用神：应爻被冲就不能相合，克世就有私心。应爻是被托付的人，所以落空就不出力，破就不专心；旺相而向着我就看重，休囚而帮着我就看轻；冲世爻是误事，克世爻是存着自己的私欲；合处遇到冲，成了又散。这几条，是请媒人时要引以为戒的。
>
> *Rule (our summary):* Engaging a go-between is the same as entrusting someone, so use the Other line: if it is clashed it cannot combine, and if it controls Self it has private motives. The Other line is the one entrusted, so if Void it does not exert itself and if broken it is not devoted; strong and on my side it takes the matter seriously, resting or trapped though helping me it takes it lightly; clashing Self it spoils the matter, controlling Self it keeps desires of its own; a combination that meets a clash is made and then undone. These are the cautions for asking a go-between.
