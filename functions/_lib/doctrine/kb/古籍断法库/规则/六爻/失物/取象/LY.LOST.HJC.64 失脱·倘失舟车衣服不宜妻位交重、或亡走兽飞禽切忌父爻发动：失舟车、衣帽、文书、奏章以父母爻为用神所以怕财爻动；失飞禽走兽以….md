# 失脱·倘失舟车衣服不宜妻位交重、或亡走兽飞禽切忌父爻发动：失舟车、衣帽、文书、奏章以父母爻为用神所以怕财爻动；失飞禽走兽以子孙为用神所以怕父爻发动，被克就难找

六爻 · 失物 · 取象 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 如果丢了船、车、衣服，不适宜妻财爻位交重发动；或者丢了走兽飞禽，切忌父母爻发动。失脱不能专门拿财当用神：如果丢的是船、车、衣帽、文书、奏章，就以父母爻为用神，所以忌讳财爻动；如果丢的是飞禽走兽，就以子孙爻为用神，所以忌讳父母爻发动，被克就难找。学习要通达变化。
>
> *Rule (our summary):* If a boat, cart or clothes are lost, it is unfit for the Wealth position to be crowded with movement; or if a beast or bird has run off, the Resource line moving is to be strictly avoided. In lost goods one cannot take Wealth alone as the Subject: if what is lost is a boat, cart, clothes, a cap, documents or memorials, the Resource line is the Subject, so a moving Wealth line is feared; if what is lost is a bird or beast, Output is the Subject, so a moving Resource line is feared, and if it is controlled the animal is hard to find. One should learn to be adaptable.
