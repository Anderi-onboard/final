# 失脱·兄动劫财若卜起赃无须觅：卜起赃和寻物，只要见到兄弟发动，财物都会失散，终究找不回来

六爻 · 失物 · 寻得 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 兄弟发动劫财，如果占起获赃物就不必去找了。占起赃和寻物，只要见兄弟发动，都主财物失散，终究难找。
>
> *Rule (our summary):* A Peer line moving robs Wealth; if one divines for recovering the stolen goods, there is no need to look. In divining for recovering stolen goods or searching for things, if a Peer line is seen moving, the goods are scattered and in the end hard to find.
