# 世空不妨，需鼎困豫家人诸卦始难终如意；卖货宜动

六爻 · 求财 · 难易 · 出处 [[海底眼]]

> [!abstract] 规则(整理,不是原文)
> 世爻空亡也不妨，比如需、鼎、困、豫、家人这几卦，开头虽然艰难，终究能如意；如果是卖货，宜于动。
>
> *Rule (our summary):* The Self falling Void does no harm; in hexagrams such as Xu, Ding, Kun, Yu and Jia Ren, though hard at first, in the end it can be as wished; if it is for selling off goods, movement suits.
