# 卦中无财：福能生财，福爻旺相必遂；无财无福，月令有财亦成，日辰是财当日亦有，谓之无中生有

六爻 · 求财 · 有无 · 出处 [[海底眼]]

> [!abstract] 规则(整理,不是原文)
> 卦里没有财，别忘了福德能生财，只要福爻旺相，一定如愿；卦里既没有财也没有福，月令里有财也能成；日辰是财，当天也有；这叫无中生有。凡是有财的卦也是这样，不可错过，要谨慎。
>
> *Rule (our summary):* If a hexagram has no Wealth, remember that Output can generate Wealth, and if the Output line is thriving it is sure to be fulfilled; where the hexagram has neither Wealth nor Output, Wealth held by the month can still bring it about; if the Day is Wealth there is money that day; this is called producing something from nothing. The same holds for hexagrams that do have Wealth; it should not be missed, and one should be careful.
