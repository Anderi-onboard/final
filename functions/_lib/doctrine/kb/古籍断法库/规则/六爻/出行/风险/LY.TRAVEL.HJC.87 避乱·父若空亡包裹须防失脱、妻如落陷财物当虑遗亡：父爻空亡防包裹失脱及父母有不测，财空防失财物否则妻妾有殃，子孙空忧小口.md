# 避乱·父若空亡包裹须防失脱、妻如落陷财物当虑遗亡：父爻空亡防包裹失脱及父母有不测，财空防失财物否则妻妾有殃，子孙空忧小口

六爻 · 出行 · 风险 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 父爻空亡，不只是包裹会丢失，还要提防父母有意想不到的忧患；财爻空了，要提防丢失财物，否则妻妾有灾；子孙空，就担忧小孩。
>
> *Rule (our summary):* If the Resource line is Void, not only may the baggage be lost but one must guard against some unforeseen worry for the parents; if Wealth is Void, guard against losing goods, or else wife and concubines meet trouble; if Output is Void, there is worry for the small children.
