# 行人·世克用而俱动转往他方：不宜世克用爻，用爻安静受克仍在旧处，用爻发动人已起程，世动克它而用爻也动则转往别处

六爻 · 出行 · 平安 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 不宜世爻克用爻：用爻安静受克，人还在原来的地方；用爻发动，人已经起程；被发动的世爻克它而用爻也动，就转往别处。
>
> *Rule (our summary):* It is unfit for the Self to control the Subject line: if the Subject is still and controlled, the man is still in the old place; if it moves, he has already set out; if a moving Self controls it and the Subject also moves, he turns and goes elsewhere.
