# 出行·一卦如无鬼煞方得如心：官鬼主祸灾，不宜见到；即使出现，安静或有制伏，也无妨

六爻 · 出行 · 总则 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 官鬼主祸灾，所以整个卦最好没有鬼煞；即使出现了，只要安静或者有制伏，见到也无妨。
>
> *Rule (our summary):* Pressure governs calamity, so the best hexagram has no baleful Pressure at all; even if it appears, if it is still or restrained there is no harm in seeing it.
