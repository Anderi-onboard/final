# 出行章·世爻旺相宜行、应若空亡且止：世是出行的人，生旺有气则吉，动而化吉或化子孙更吉，休囚空破、动而化凶则不宜行；应是地头与依傍之人，空破墓绝或变鬼变绝回头克，去也无益

六爻 · 出行 · 去留 · 出处 [[增删卜易]]

> [!abstract] 规则(整理,不是原文)
> 世爻是出行的人，旺相有气就适宜出行；发动化出吉的爻、化出子孙更吉；休囚空破，或者发动化出凶的，就不宜出行。应爻是目的地，又是依傍的人，应爻空亡就该停下；应爻空破墓绝，或者发动变鬼、变绝、化出回头克，去了也没有益处。
>
> *Rule (our summary):* The Self line is the one who goes: if it is strong and has breath it is fit to set out, it is better still if it moves and changes into something lucky or into Output, and it is unfit to set out if it is resting or trapped, Void or broken, or moves and changes into something ill. The Other line is the destination and also the person one leans on: if the Other is Void one should stop, and if it is Void, broken, in the tomb or extinct, or moves and changes into Pressure, into extinction or into a line that turns back to control it, going is of no use.
