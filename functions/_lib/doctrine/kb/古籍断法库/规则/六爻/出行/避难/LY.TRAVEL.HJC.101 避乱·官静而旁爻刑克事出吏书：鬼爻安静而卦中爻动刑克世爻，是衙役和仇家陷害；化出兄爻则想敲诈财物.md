# 避乱·官静而旁爻刑克事出吏书：鬼爻安静而卦中爻动刑克世爻，是衙役和仇家陷害；化出兄爻则想敲诈财物

六爻 · 出行 · 避难 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 鬼爻安静，而卦中有爻发动刑克世爻的，是衙役和仇家陷害；如果化出兄爻，他们是想敲诈财物。
>
> *Rule (our summary):* If Pressure is still but a moving line in the hexagram punishes or controls the Self, it is yamen runners and enemies framing one; if it changes into a Peer line, they want to extort money.
