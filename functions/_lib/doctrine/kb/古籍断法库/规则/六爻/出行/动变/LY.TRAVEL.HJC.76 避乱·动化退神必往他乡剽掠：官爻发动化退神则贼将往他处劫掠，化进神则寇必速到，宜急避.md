# 避乱·动化退神必往他乡剽掠：官爻发动化退神则贼将往他处劫掠，化进神则寇必速到，宜急避

六爻 · 出行 · 动变 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 官爻发动，如果化出退神，贼将到别处劫掠；如果化出进神，贼寇必定很快就到，应该赶快躲避。
>
> *Rule (our summary):* If the Pressure line moves and changes into a Retreating spirit, the bandits are going to plunder elsewhere; if it changes into an Advancing spirit, the bandits will surely arrive quickly and one should hurry to hide.
