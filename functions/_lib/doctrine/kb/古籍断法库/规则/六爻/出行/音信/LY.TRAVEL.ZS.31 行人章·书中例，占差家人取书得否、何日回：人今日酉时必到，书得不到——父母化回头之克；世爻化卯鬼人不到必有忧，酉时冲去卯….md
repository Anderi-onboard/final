# 行人章·书中例，占差家人取书得否、何日回：人今日酉时必到，书得不到——父母化回头之克；世爻化卯鬼人不到必有忧，酉时冲去卯木则无忧

六爻 · 出行 · 音信 · 出处 [[增删卜易]]

> [!abstract] 规则(整理,不是原文)
> 动爻化出克它的爻最凶；文书以父母爻为用神，化出回头克就得不到书。书中例：辰月丙申日占派家人去取书能不能取到、哪天回来，得渐卦变剥卦：仆人今天酉时必到，书得不到。问怎么知道的，我说：巳火父母化出回头之克，所以得不到书；甲子持世化出卯木官鬼，人不到必有忧虑，今天酉时冲去卯木，就没有忧了；果然酉时到了，而书没有取到。
>
> *Rule (our summary):* A movement that changes into a controlling line is the most ill; a document is read from the Resource line, and if it changes into a turning-back control the document is not obtained. Worked example: in the Chen month, on a Bingshen day, a man divined whether a household servant sent to fetch a book would get it and on what day he would return, and got Jian changing to Bo: the servant will surely arrive this day in the You hour, but the book will not be had. Asked how I knew, I said: the Resource Si-fire changes into a turning-back control, so the book is not obtained; Jiazi holds the Self and changes into the Pressure Mao-wood, so if he did not arrive there would surely be worry, but this day in the You hour the clash removes the Mao-wood, so there is no worry. He did arrive in the You hour, and the book was not got.
