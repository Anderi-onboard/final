# 避乱·动来刑害总教智慧也难逃、变入空亡若被勾留犹可脱：鬼动不伤世任它猖獗也不遭祸，被刑冲克害必难逃，官爻变入死墓空绝是虎头蛇尾

六爻 · 出行 · 避难 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 鬼爻发动但不伤世，任凭它猖獗也不遭祸；如果被它刑冲克害，必定难逃；如果官爻变入死、墓、空、绝，就是虎头蛇尾，虽有凶，却是没有灾咎的征兆，即使被拘留也还有可能脱身。
>
> *Rule (our summary):* If Pressure moves without injuring the Self, however rampant it is one meets no disaster; if one is punished, clashed, controlled or harmed by it, escape is surely hard; if the Pressure line changes into death, tomb, Void or extinction, it is a tiger's head and a snake's tail: there is ill, but it is a sign of no blame, and even if one is detained there is still the chance to get free.
