# 避乱·子来冲动皆因儿哭惹成灾：鬼爻安静最吉，若被子孙冲动，必有小孩啼叫被发觉而受害；福神旺相官鬼衰弱则无妨

六爻 · 出行 · 避难 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 鬼爻安静最吉，如果被子孙冲动，必定有小孩啼哭叫喊，因此被发觉，遭到他们的害；如果福神旺相、官鬼衰弱，就无妨。
>
> *Rule (our summary):* Pressure still is the best; if Output clashes it into movement, a small child will surely cry out, and so the hiders are discovered and harmed by them; if Output is strong and Pressure weak, there is no harm.
