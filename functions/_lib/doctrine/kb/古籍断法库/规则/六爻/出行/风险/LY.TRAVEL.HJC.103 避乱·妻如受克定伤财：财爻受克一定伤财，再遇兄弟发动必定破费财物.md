# 避乱·妻如受克定伤财：财爻受克一定伤财，再遇兄弟发动必定破费财物

六爻 · 出行 · 风险 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 财爻如果受克，一定要伤财；如果又遇到兄弟发动，必定破费钱财。
>
> *Rule (our summary):* If the Wealth line is controlled, money is surely lost; if a Peer line also moves, there will surely be expense and loss of money.
