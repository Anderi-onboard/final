# 词讼·应动则他多机变：世动我必用心谋划，若化官鬼兄弟回头克制反为失计；应动他必有谋，加月建必有贵人依靠，克世则不吉

六爻 · 官非 · 胜负 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 应爻发动，他就多有机变。世爻发动，我必定用心谋划，如果化出官鬼或兄弟回头克制，反而失策；应爻发动，他必定有谋划，如果加上月建，必有贵人依靠，克世爻就不吉。
>
> *Rule (our summary):* If the Other moves, he has many tricks and changes. If the Self moves, I surely lay plans with care, but if it changes into Pressure or Peer that turns back to control it, the plan misfires; if the Other moves, he surely has a scheme, and if the Month is added he surely has a noble to lean on, and if it controls the Self it is unlucky.
