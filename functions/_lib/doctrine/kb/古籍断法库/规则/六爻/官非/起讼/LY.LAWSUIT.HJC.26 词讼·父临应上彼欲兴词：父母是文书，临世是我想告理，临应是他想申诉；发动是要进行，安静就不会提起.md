# 词讼·父临应上彼欲兴词：父母是文书，临世是我想告理，临应是他想申诉；发动是要进行，安静就不会提起

六爻 · 官非 · 起讼 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 父母临在应爻上，他想要起诉。父母是文书，临在世爻上，是我想告理；临在应爻上，是他想申诉；发动是想要进行，安静就不会提起。
>
> *Rule (our summary):* With Resource on the Other, he wants to file a suit. Resource is the papers; on the Self, I want to lodge the case; on the Other, he wants to file his plea; moving, it is going ahead; still, it will not be raised.
