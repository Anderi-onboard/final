# 求名·两用相冲题目生疏而不熟：官爻为用爻喜合不喜冲，见官爻相冲主出题生涩不熟

六爻 · 考试 · 取象 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 两个用爻互相冲，出的题目生僻不熟；官爻是用爻，喜合不喜冲，见官爻相冲，主出题生涩、不熟悉。
>
> *Rule (our summary):* If the two Subject lines clash each other, the topic set is strange and unfamiliar; the Pressure line is the Subject line and likes combination and not clash, and if two Pressure lines clash each other the topic set is obscure and unfamiliar.
