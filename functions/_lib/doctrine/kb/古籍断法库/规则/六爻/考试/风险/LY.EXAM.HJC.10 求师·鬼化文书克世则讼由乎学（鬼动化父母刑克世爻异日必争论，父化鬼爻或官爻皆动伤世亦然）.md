# 求师·鬼化文书克世则讼由乎学（鬼动化父母刑克世爻异日必争论，父化鬼爻或官爻皆动伤世亦然）

六爻 · 考试 · 风险 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 官鬼变出文书（父母）来克世，会因学业上的事引出官司；官鬼动变父母刑克世爻，日后一定有争论；父爻变官鬼，或官爻都动来伤世，也一样。
>
> *Rule (our summary):* If Pressure changes into the document line and controls the Self, a lawsuit will arise from the schooling; if the Pressure line moves and changes into Resource and punishes and controls the Self, there will surely be dispute in future; the same if the Resource line changes into the Pressure line, or the Pressure lines all move and harm the Self.
