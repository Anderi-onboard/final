# 求名·岁加有气之官终登黄甲：太岁最喜有情，临鬼爻是人臣面君之象，更得生旺有气必然名姓高标

六爻 · 考试 · 成否 · 出处 [[黄金策]]

> [!abstract] 规则(整理,不是原文)
> 太岁加在有气的官爻上，终究登上黄甲：太岁最喜有情，临官鬼爻是臣子面见君主的象，再得生旺有气，名姓必然高高标榜。
>
> *Rule (our summary):* If Tai Sui is added to a Pressure line that has breath, one will in the end enter the Yellow List: Tai Sui most wants to be favourable, standing on the Pressure line is the image of a minister before his sovereign, and if it is further given life and strength and has breath, one's name will surely be set high.
