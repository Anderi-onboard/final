# 福鬼若值青龙方宜种痘：子孙爻或官鬼爻临青龙、不遇日月动爻刑冲克害，占种痘大吉；官爻旬空或伏藏、福神不值青龙，种了也出不来

六爻 · 疾病 · 痘疹 · 出处 [[卜筮正宗]]

> [!abstract] 规则(整理,不是原文)
> 福神或鬼爻如果带青龙，才适合种痘：子孙爻带青龙，或者官鬼爻带青龙，没有遇到日、月、动爻的刑冲克害，占种痘是大吉的兆头；如果官爻旬空或者伏藏，福神又不带青龙，即使种了痘也出不来。
>
> *Rule (our summary):* Output or Pressure carrying the Azure Dragon means it is fit to inoculate: if the Output line carries the Azure Dragon, or the Pressure line carries the Azure Dragon, and meets no punishment, clash, control or harm from the Day, Month or moving lines, then in divining about inoculation it is a very auspicious sign; if the Pressure line is Void or hidden and Output does not carry the Azure Dragon, then even if the pox is sown it will not come out.

^q2

> [!note] 按
> 「种痘」是把痘浆或痘痂接种到健康人身上，让他出一次轻的痘，以后不再得重的；「栽花」是它的雅称。注里「种豆」是「种痘」的误字。这是书里唯一讲种痘的一处。
>
> *Note:* 'Sowing the pox' (zhong dou) is inoculating a healthy person with pox matter so that he has a light case and does not get a severe one later; 'planting flowers' is its elegant name. The commentary's 'zhong dou' written with the bean character is a mis-write of the same. This is the only place in the book that treats inoculation.
