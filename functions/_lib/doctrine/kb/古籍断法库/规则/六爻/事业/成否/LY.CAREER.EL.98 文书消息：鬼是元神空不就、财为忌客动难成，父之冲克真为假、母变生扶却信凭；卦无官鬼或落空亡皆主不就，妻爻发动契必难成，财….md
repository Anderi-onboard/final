# 文书消息：鬼是元神空不就、财为忌客动难成，父之冲克真为假、母变生扶却信凭；卦无官鬼或落空亡皆主不就，妻爻发动契必难成，财动官亦动反能成契，父母若被日月冲破或化绝化空此契不能见信于人，父母若遇生扶或变为有气此书纵假而可为真

六爻 · 事业 · 成否 · 出处 [[易林补遗]]

> [!abstract] 规则(整理,不是原文)
> 官鬼是元神，落空就办不成；财是忌神，发动就难成；父爻被冲克，真的也成了假的；父母爻变出生扶它的爻，就有信凭。具体说：卦里没有官鬼，或者官鬼落空亡，都主办不成；妻爻发动，契约必定难成；财动官也动，反而能成契约；父母爻如果被日月冲破，或者化绝、化空，这份契约不能取信于人；父母爻如果遇到生扶，或者变成有气，这份文书即使是假的也可以当真。
>
> *Rule (our summary):* Pressure is the Support, and if Void it does not succeed; Wealth is the Adversary, and if it moves it is hard to accomplish; if Resource is clashed or controlled, the genuine turns false; if Resource changes and is generated and supported, it gains credence. In detail: if the hexagram has no Pressure or it falls on Void, all mean it will not succeed; if the wife line, Wealth, moves, the contract will surely be hard to complete; if Wealth moves and the star of office also moves, on the contrary the contract can be completed; if Resource is clashed or broken by the Day or Month, or changes into extinction or Void, this contract cannot be believed by others; if Resource meets generation and support, or changes into something with qi, then even if this document is false it can be taken as true.

> [!note] 按
> 「元神」是生用神的爻，「忌客」按文意是忌神（见术语表）：这里用神是父母（文书），官鬼生父母所以是元神，财克父母所以是忌神。「母」是父母爻。末两句「父之冲克真为假，母变生扶却信凭」「此书纵假而可为真」书里就是这样说的：文书取不取信于人，看父母爻的旺衰生克；这里照字面译，不替它加解释。
>
> *Note:* 'Yuanshen', the Support, is the line that generates the Subject, and 'jike', the Adversary guest, is by the sense the Adversary (see the glossary): here the Subject is Resource (the document), so Pressure, which generates Resource, is the Support, and Wealth, which controls Resource, is the Adversary. 'Mu', mother, is the Resource line. The last two statements, 'if Resource is clashed or controlled, the genuine turns false; if Resource changes and is generated and supported, it gains credence' and 'even if this document is false it can be taken as true', are exactly what the book says: whether a document is believed depends on the strength, generation and control of the Resource line; it is translated literally here, with no explanation added.
