# 征战占·六亲（三）：财旺相粮草丰足，衰败无余，墓胎不发，空绝或卦无财粮草缺绝；子化财向邻国呼庚；财加武动下人偷窃；内兄动克财督饷侵渔；外兄动克财敌人劫掠

六爻 · 事业 · 军旅 · 出处 [[易隐]]

> [!abstract] 规则(整理,不是原文)
> 粮草：财爻旺相，粮草丰足；衰败，没有余粮；临墓、胎，粮草发不下来；落空、绝，或卦里没有财爻，粮草断绝。子孙变出财爻的，向邻国借粮（呼庚）；财爻加玄武发动的，下面的人偷窃；内卦的兄爻发动克财爻的，督办粮饷的人侵吞中饱；外卦的兄爻发动克财爻的，敌人劫掠。
>
> *Rule (our summary):* Provisions. If Wealth is thriving, provisions are ample; if spent, there is no surplus; if on tomb or womb, provisions are not issued; if Void or extinct, or the hexagram has no Wealth, provisions are cut off. If Output turns into Wealth, one begs grain from a neighbouring state; if Wealth carries the Dark Tortoise and moves, those below steal; if an inner Peer line moves to control Wealth, the official in charge of supplies embezzles; if an outer Peer line moves to control Wealth, the enemy plunders.

^q1

> [!note] 按
> 「呼庚」即「呼庚癸」，出自《左传》，军中向人讨粮的暗语；「侵渔」是侵吞百姓或公家的钱粮。原文是「呼庚邻国」，字面是向邻国呼庚。
>
> *Note:* 'Hugeng' is 'hu geng gui', from the Zuo Zhuan, the code words for begging for grain in an army; 'qinyu' is embezzling the money and grain of the people or the government. The text reads 'hu geng neighbouring state', by the letter calling 'geng' to a neighbouring state.
