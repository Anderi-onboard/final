# 官员荐奖：鬼化子爻荐贤未听、官之财象奖励能从；荐与奖皆以官为主旺者来速衰则来迟，动化子孙虽荐未能听信，财来助鬼奖得如心

六爻 · 事业 · 动变 · 出处 [[易林补遗]]

> [!abstract] 规则(整理,不是原文)
> 官鬼化成子孙爻，推荐贤能就不被听从；官爻变成财的象，奖励就能被应允。荐举和奖励，都以官爻为主：旺的来得快，衰的来得迟；官爻发动化成子孙，即使有人推荐也不被听信；财爻来帮助官鬼，奖励就能如愿。
>
> *Rule (our summary):* If Pressure changes into an Output line, the recommendation of the worthy is not heeded; if the star of office changes into the Wealth image, the award can be granted. Both recommendation and award take the star of office as the chief: if it is thriving it comes quickly, if weak it comes late; if it moves and changes into Output, even if one is recommended it is not heeded and believed; if Wealth comes to aid Pressure, the award is obtained as one wishes.

> [!note] 按
> 「荐贤」是荐举贤能。这一条与前面仕宦升迁「官化子孙非降即调」「官若化财平升品级」（EL.56）取同一个关系，这里换到荐举、奖励上：官变子孙是失，官变财是得。
>
> *Note:* 'Jianxian' is recommending the worthy. This entry takes the same relation as 'if Pressure changes into Output it is demotion or transfer' and 'if Pressure changes into Wealth, a level promotion' (EL.56) in the earlier chapter on official promotion, here moved to recommendation and award: Pressure changing into Output is a loss and Pressure changing into Wealth is a gain.
