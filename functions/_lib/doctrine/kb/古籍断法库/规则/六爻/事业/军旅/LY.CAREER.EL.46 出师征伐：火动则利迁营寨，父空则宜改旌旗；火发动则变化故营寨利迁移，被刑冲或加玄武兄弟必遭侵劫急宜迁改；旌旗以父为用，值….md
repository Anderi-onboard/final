# 出师征伐：火动则利迁营寨，父空则宜改旌旗；火发动则变化故营寨利迁移，被刑冲或加玄武兄弟必遭侵劫急宜迁改；旌旗以父为用，值旬空月破必然损伤急须改换

六爻 · 事业 · 军旅 · 出处 [[易林补遗]]

> [!abstract] 规则(整理,不是原文)
> 火发动，利于迁移营寨；父爻落空，宜改换旌旗。军营以火为用，火如果发动，动就是变化，所以营寨利于迁移才吉；如果被刑、冲，或者加玄武、加兄弟，必遭侵劫，急宜迁改。旌旗以父爻为用，如果值旬空、月破，必然损伤，急须改换。
>
> *Rule (our summary):* If Fire moves, it favours moving the camp; if the Resource line is Void, it is fit to change the banners. The army camp takes Fire as the Subject, and if Fire moves, moving means change, so it is auspicious to move the camp; if it is punished or clashed, or the Dark Tortoise or Peer is added, the camp will surely be raided, and it should be moved and changed urgently. The banners take the Resource line as the Subject, and if it meets decade Void or Month-break they are surely damaged and must be changed urgently.
