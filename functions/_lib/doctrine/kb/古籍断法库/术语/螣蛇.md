# 螣蛇 · Coiling Snake

*téngshé*

六神之一,主虚惊、怪异、牵缠。

One of the six spirits: false alarms, oddities, entanglement.

原文里写作「螣蛇」时,英文一律译作 **Coiling Snake**。
