# 进神 · Advancing

*jìnshén*

同一五行往前变(如寅化卯),主越来越盛。

A line turns into the next branch of the same element (e.g. Yin into Mao): growing stronger.

原文里写作「进神」时,英文一律译作 **Advancing**。
