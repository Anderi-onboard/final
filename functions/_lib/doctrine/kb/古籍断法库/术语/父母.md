# 父母 · Resource

*fùmǔ*

六亲之一,生我者。它克子孙,断了财的来源,占财时叫「绝源杀」;又主辛劳、文书、契约。

One of the six relations: the element that generates the Self. It controls Output and so cuts off the source of money (the classics call it the killer of the source); it also means toil, documents and contracts.

原文里写作「父母」「父爻」时,英文一律译作 **Resource**。
