# 冲 · clash

*chōng*

子午、丑未、寅申、卯酉、辰戌、巳亥六对相冲。冲静爻为暗动,冲空为实,冲合为开,冲衰爻为破。

The six opposed branch pairs. A clash stirs a still line, fills a void one, opens a combination, and breaks a weak line.
