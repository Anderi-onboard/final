# 兄弟 · Peer

*xiōngdì*

六亲之一,与我同类者。它克妻财,占财最忌,书上叫「劫财」「劫杀」;也主同伴、竞争者、耗费。

One of the six relations: the same element as the Self. It controls Wealth, so it is the worst sign in a money question (the classics call it the robber of wealth); it also stands for partners, rivals and spending.

原文里写作「兄弟」「兄爻」时,英文一律译作 **Peer**。
