# 古籍全文库

断卦要用的古籍全文。一本书一个 `.txt`，UTF-8 编码，简体字。正文 61 本、约 319 万字，按门类放在五个文件夹里；
另有 7 本「参校本」放在 `六爻/参校本/`，是校对时拿来比的外部版本。
这个文件夹在 `functions/_lib/` 下面，网站不会把它当网页发出去（和提示词同一个位置）。

## 你那七本（`六爻/`）用的是你那份合集

`增删卜易` `卜筮正宗` `火珠林` `卜筮大全` `易隐` `易林补遗` `易冒` 这七个文件，现在的文字来自你给的那份合集，不是网上的版本。

你那份 docx 里的字全是乱码：每个字被换成了编码表里排在它前面的另一个字。比如《增删卜易》序的第一句，文件里是

```
野鹤曰：卜敨丧道，乃伏羲、敋狴、周俬、孔子四圸圂乎丧徉泋丰。
```

还原出来是

```
野鹤曰：卜易之道，乃伏羲、文王、周公、孔子四大圣人之心法也。
```

还原分三步：

1. 程序按「乱码字 → 真字」的对应表，加上上下文，把每个字猜出来。
2. 网上能找到同一本书的（殆知阁本、维基文库本，见下面「参校本」），一句一句对，对上的字就定下来。
3. 程序拿不准的、和参校本对不上的，人工一条一条看。一共看了四张清单：参校本和程序不一致、程序改成了参校本读法的 231 处；参校本读法不同、程序没改的 1955 处；程序自己拿不准的 1168 处；乱码字从来没见过的 116 处。另外按规则扫了几类容易错的字：「甲/申」（乱码里是同一个字形）、「巳/己/已」、「初/一」、「卦/向」，以及《卜筮大全》里「【某字】读音：……」这种注音行里被注的那个字。

### 「按照你的来」是怎么处理的

- **你那份和参校本都说得通，用你那份。** 比如《增删卜易》「雷天大壮，亦是六冲卦」，殆知阁本作「也是六冲卦」，保留「亦」；「子孙持世，即便开行」这类字句差异一律不改。1955 条参校本读法不同的地方，绝大多数属于这种。
- **你那份自己错了，改掉，并记在 `六爻/校记.md`。** 每条写着在哪一行、原来是什么字、为什么改。比如：
  - 《增删卜易》「即是未**出**变出戌土」→「即是未**土**变出戌土」（两种外部版本都作「土」）
  - 《卜筮正宗》「以化出巳火父母爻为用，**日**建克之，寅水原神又被日辰冲克」→「**月**建克之」（同一句后面已经说了日辰，前面只能是月建）
  - 《火珠林》「目前凶事**始**须吉」→「**终**须吉」；《易林补遗》「**内干外巽**」→「**内乾外巽**」（卦名「乾」被繁转简错成了「干」，这本里有 82 处）
- 拿不准的改动，校记里写了「存疑」。

### 准不准

- **外部版本里找得到同一句的字**：和另一个版本逐字对过，两边不一样的地方（上面那 231 + 1955 条）人工看过。
- **只靠还原的字**：之前拿有外部版本可对的段落做过测试——不看外部版本、只靠程序还原，每 1000 字错 2 到 3 个（量的）。这次把程序自己拿不准的 1168 处全部看过，改了 107 处；最后随机抽了 24 段、约 1700 字通读，没发现错字（量的，但样本小）。剩下的错字估计每 1000 字不到 1 个（估的，没有逐字核）。
- **要把哪一句写进判据库，仍以影印本那一页为准**：你那份合集本身也是录入本，录入时的错字我只改了能确定的。

### 参校本

`六爻/参校本/` 里的 7 个文件是上一版用的网上版本，文件名后面标了「（殆知阁本）」。《卜筮大全》那本在殆知阁叫《卜筮全书》，是同一本书。它们比你那份少东西：《卜筮正宗》少了黄金策各章的大段注解（6.8 万字对 11.1 万字），《增删卜易》少了今人按语（10.8 万对 16.4 万），《火珠林》只有正文、没有后面附的《通玄妙论》《阐奥歌章》《天玄赋》（1.7 万对 6.2 万）。留着是为了以后要对某一句时有另一个版本可看。

## 其余 54 本改过什么

原文是网上的转录本，有四类毛病，已经改掉：

1. **「乾」被繁转简错成了「干」，改回 275 处。** 比如《京氏易传》原来是「【干下干上】干纯阳用事」，现在是「【乾下乾上】乾纯阳用事」。只改六爻、梅花、奇门三类书里确定是卦名、宫名的地方：`干为天` `干宫` `干兑` `【干下坤上】` `乾一兑二` 这种。「天干」「干支」「日干」「阳干」「干燥」「无干」「干蛊」这些本来就是「干」，没动。每本改了几处：京氏易传 37、梅花易数 46、皇极经世心易发微 27、奇门遁甲秘笈大全 25、御定奇门宝鉴 6、烟波钓叟歌 1；参校本里的卜筮正宗 82、易林补遗 51。
   **大六壬的书一处没改**：「干上」「干为天」在壬学里是正经术语（日干上神、干为天支为地），分不清哪些是被转错的。
2. **私用区字符（换个字体就显示成方框的自造字）换成「□」，1087 处。** 大多是卦符和四库本的专用字形，标准编码里没有对应的字，还原不了。最多的是《卜法详考》817 处、《京氏易传》100 处（每一卦开头的卦符）、《大易断例卜筮元龟目》72 处、《六壬神课金口诀古本》43 处。
3. **参校本《卜筮正宗》里 998 个英文问号，其实是丢了的句号**，比如「动静阴阳，反复迁变？虽万象之纷纭」。改成「。」；前一个字是乎、哉、何、耶这类的改成「？」。
4. 其他书里的英文问号本来就是问号，321 个换成全角「？」；《奇门遁甲元灵经》3 处「？；」改回「·」（《隋书·艺文志》）。

## 没解决的

- 除了你那七本，其余是网上转录本，不是校勘过的版本。转录时的错字、「乾/干」以外的繁转简错误，没有逐字查。
