# 古籍全文库

断卦要用的古籍全文。一本书一个 `.txt`，UTF-8 编码，简体字。一共 61 本、约 306 万字，按门类放在五个文件夹里。
这个文件夹在 `functions/_lib/` 下面，网站不会把它当网页发出去（和提示词同一个位置）。

## 这批文字改过什么

原文是网上的转录本，有四类毛病，已经改掉：

1. **「乾」被繁转简错成了「干」，改回 275 处。** 比如《京氏易传》原来是「【干下干上】干纯阳用事」，现在是「【乾下乾上】乾纯阳用事」。只改六爻、梅花、奇门三类书里确定是卦名、宫名的地方：`干为天` `干宫` `干兑` `【干下坤上】` `乾一兑二` 这种。「天干」「干支」「日干」「阳干」「干燥」「无干」「干蛊」这些本来就是「干」，没动。每本改了几处：京氏易传 37、卜筮正宗 82、易林补遗 51、梅花易数 46、皇极经世心易发微 27、奇门遁甲秘笈大全 25、御定奇门宝鉴 6、烟波钓叟歌 1。
   **大六壬的书一处没改**：「干上」「干为天」在壬学里是正经术语（日干上神、干为天支为地），分不清哪些是被转错的。
2. **私用区字符（换个字体就显示成方框的自造字）换成「□」，1087 处。** 大多是卦符和四库本的专用字形，标准编码里没有对应的字，还原不了。最多的是《卜法详考》817 处、《京氏易传》100 处（每一卦开头的卦符）、《大易断例卜筮元龟目》72 处、《六壬神课金口诀古本》43 处。
3. **《卜筮正宗》里 998 个英文问号，其实是丢了的句号**，比如「动静阴阳，反复迁变?虽万象之纷纭」。改成「。」；前一个字是乎、哉、何、耶这类的改成「？」。
4. 其他书里的英文问号本来就是问号，321 个换成全角「？」；《奇门遁甲元灵经》3 处「?;」改回「·」（《隋书·艺文志》）。

## 没解决的

- 这些是网上转录本，不是校勘过的版本。转录时的错字、「乾/干」以外的繁转简错误，没有逐字查。**要把哪一句写进判据库，以影印本那一页为准。**
- 大六壬书里可能也有被转错的「乾」，见上面第 1 条。
