# 书单：五门的权威书目（2026-09-26）

梅花易数、六爻、大六壬、奇门遁甲、紫微斗数，每一门分三块：古籍、近现代书、名师课程。
「权威」按的是网上几份推荐书目里反复出现的，出处附在每一门后面；这些书我没有全读过。

每一条标了两件事：

- **库里**：✅ 有；⚠️ 有，但不全；⬜ 没有
- **怎么拿**：
  - 古籍是公版，能找到文字或扫描就能收；
  - 「已过版权期」是作者去世超过 50 年的近现代书（中国大陆的版权期），原版扫描能收；
  - 其余近现代书和课程有版权，要买书或者跟老师要。

## 不全的书，这次补到哪了

| 大六壬 | 从道藏补收了《黄帝龙首经》《黄帝金匮玉衡经》《黄帝授三子玄女经》三部早期经典 | —— |
| 紫微斗数全书 | 找到了更全的明刊七卷本（书格，免费扫描） | 把扫描转成文字 |
| 古今图书集成·奇门 | 查清了缺的是卷七百三到七百十二里除七百六以外的九卷 | 国学大师网的文字本（这里连不上），或者维基文库扫描转文字 |
| 遁甲符应经 | 确认卷下只在扫描本里 | 古籍藏览网的影印本转文字，或者订阅 ctext |
| 六壬经纬 | 卷二是排盘表，ctext 有几个版本的扫描 | 扫描转文字；排盘表也可以用排盘程序生成 |
