# 第二步 · 日月:谁说了算

月建和日辰是四处生克源头的头两处。这一步决定每一爻的旺衰,
而旺衰决定第三步那笔生克算不算数。

| id | 断法 | 出处 |
|---|---|---|
| SOP-2.1 | 月建生、扶、比、拱、合 → 旺相 | 摘要 |
| SOP-2.2 | 月建冲 → 月破 | 摘要 |
| SOP-2.3 | 动而逢生为假破 | 摘要 |
| SOP-2.4 | 月建能制服卦中动爻与变爻 | 摘要 |
| SOP-2.5 | 日冲旺相静爻 = 暗动 | 摘要 |
| SOP-2.6 | 日冲衰弱静爻 = 日破 | 摘要 |
| SOP-2.7 | 日辰冲起旬空(冲空则实) | 摘要 |
| SOP-2.8 | 日辰冲开合局(合处逢冲) | 摘要 |
| SOP-2.9 | 不为空五条:动、旺、得日月动爻生扶、动化空、伏而旺相 | 摘要 |
| SOP-2.10 | 真空:春土 夏金 秋木 冬火 | 摘要 |
| SOP-2.11 | 真空:休囚无气静而受克 | 摘要 |

⚠️ **2.2 和 2.3 不是两条按顺序跑的规则,是一条判据的两半。**
月冲叫月破,但那一爻如果正在动、又得生,它就是假破 —— 先判月破再判假破,
和一次性判完,结果一样;分成两条写会让人以为要跑两遍。

```
SOP-3.忌神.不能克.1  忌神休囚不动，动而休囚被日月动爻克者，一也。
SOP-3.忌神.不能克.2  忌神静临空破，二也。
SOP-3.忌神.不能克.3  忌神入三墓，三也。
SOP-3.忌神.不能克.4  忌神衰动化退神，四也。
SOP-3.忌神.不能克.5  忌神衰而又绝，五也。
SOP-3.忌神.不能克.6  忌神动化绝化克、化破、化散，六也。
SOP-3.忌神.不能克.7  忌神与元神同动，七也。
```

⚠️ **「能」和「不能」会同时命中同一条关系。** 比如一爻既旺相(能克.1 的反面不成立)
又入三墓(不能克.3)。包里定的规矩是:**取条件更具体的那一条,并且把冲突记下来**,
不是谁先跑谁赢。

## 退神四法 —— 原文,同章,印刷页 95

```
SOP-3.退神.1  退神之法有四：动旺相而化旺相，或有日月动爻生扶，占近事得时而不退者，一也。
SOP-3.退神.2  动休囚而化休囚，及时而退者，二也。
SOP-3.退神.3  动爻变爻，有一而旺相，待休囚之时而退者，三也。
```

## 三墓与出墓 —— 原文,《随鬼入墓章第三十》印刷页 98

```
SOP-3.三墓.日墓  余因屡试而得验者，只验世爻入墓有三：世爻随鬼入日墓。
SOP-3.三墓.动墓  余因屡试而得验者，只验世爻入墓有三：世爻随鬼入动墓。
SOP-3.三墓.化墓  余因屡试而得验者，只验世爻入墓有三：动而化墓。
SOP-3.三墓.冲开  占功名，世旺得地，冲开墓库之年月成名。
SOP-3.三墓.破墓  墓神被日月动爻冲破，亦非真也。墓破即如破网，容易而出矣。
```

⚠️ **三种墓不是一个东西。** 日墓等冲、月墓等出月、动墓跟着那个动爻走 ——
第五步的应期恰恰按这个分尺度。合成一个「入墓」标记,应期就算不出来。

# 第五步 · 应期:什么时候应

**10 条全有原文**,《各门类应期总注章第又二十六》印刷页 74–75。

```
SOP-5.1   [日] 静而逢值逢冲。且如主事爻，临子水不动，后逢子日午日应之。余仿此。

SOP-5.2   [日] 动而逢合逢值。且如主事爻，临子发动，后遇丑日子日应之。余仿此。

SOP-5.3   [日] 太旺者，逢墓逢冲。且如主事爻，临午火，又遇巳火，午月日占卦，
               或卦中巳午爻太多，后逢亥子日应之，又有戌日应之，乃火入墓也。余仿此。

SOP-5.4   [—] 衰绝者，遇生遇旺。且如主事爻属金，占卦于巳午月日，即是休囚无气，
               后逢土月日，或至秋令当时，则旺矣。余仿此。

SOP-5.5   [日] 入三墓，俱喜冲开。且如爻临午火，火墓于戌，后逢辰日则应之。余仿此。

SOP-5.6   [—] 遇六合，亦宜相击。且如主事爻，与月作合，或动与爻合，或动而化合，
               或凶或吉，必待冲开之日月应之。且如主象临子，与丑作合，
               后逢午未日应之。余仿此。

SOP-5.7   [日] 月破喜逢填合。且如子月占卦，主事爻临午火，乃为月破。
               后逢未日应之，谓之破而逢合。又有逢午日应之，填实之日，则不破矣。

SOP-5.8   [—] 旬空最爱填冲。《旬空章》注解极明。爻遇旬空，日辰冲起而为用，
               谓之冲空则实。

SOP-5.9   [—] 化进神，逢值逢合。且如申动化酉，乃为进神，为祸为福，
               有应申月日，有应巳月日。

SOP-5.10  [—] 化退神，忌值忌冲。即如酉动化申，有应申月日，有应寅月日。
```

`[日]` 是包里 `尺度` 字段写着「日」的,`[—]` 是那一条没写尺度。

⚠️⚠️ **应期不由问题触发,由用神状态触发。** 旬空的爻就有旬空的应期,
不管他问的是什么。所以这十条的触发条件写在**爻的状态**上,不写在事体类型上 ——
这跟前四步的路由逻辑完全不同,别照着前面那套接。

⚠️ 应期**只产候选,不改吉凶**。第四步已经定了凶,第五步只说它什么时候凶。
