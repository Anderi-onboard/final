# 白话与判词自足

## 判词剪下来也要能看懂

把任何一句承重的话剪下来，给一个没读过前文的人看 —— 他知道你在说什么吗？

| ✗ 单看不懂 | ✓ 单看能懂 |
|---|---|
| 动的是她，静的是你 | 张罗你们俩这些事的，一直是她 |
| 劲从地基上来，不是从屋顶上来 | 你们过得下去，靠的是把日子过好，不是靠还剩多少新鲜感 |
| 她的在意从嘴上来 | 她关心你的样子，就是唠叨你 |
| 你们是并排的两块土 | 她不管着你，你也不管着她 |

合格的那句永远**更短、词都是本来的意思、说的是谁做了什么**。
靠前文搭的比喻、翻译过的术语、只在位置上才成立的抽象词 —— 能当连接，不能当判词。

## 每句话要有中心

四个位置上都得站着真东西：

| 位置 | ✗ | ✓ |
|---|---|---|
| 动词 | 父母持世 —— 你被学业**托着** | 你现在是学生：时间归学校排，住的花的大半靠家里 |
| 名词 | 麻烦的是**它**坏起来不好发现 | 麻烦的是，关系坏了你不容易发现 |
| 主语 | 这种**稳**坏起来不好发现 | 关系坏了你不容易发现，因为它一直是这个样子 |
| 落地 | 动的是官鬼 | 动的偏偏是官鬼 —— 所以卡你的不是能力，是审批那一关 |

别背例子，背问题：**具体是什么动作、谁在做、然后呢？**

## 术语就地翻译

说真名（应爻、用神、旬空、月破），然后**在同一口气里**按它做什么来解释，用陌生人能核对的具体词：

✓ 应爻 —— 他那一头 —— 是空的：人在，但眼下没有任何东西从他那边过来。
✗ 应爻空，代表一种虚无。

不要拿一个术语去换另一个术语。状态词（空、墓、月破、囚）最容易停在半句：「自己还没到位」要写全 —— **什么**没到位，什么算到位。

## 比喻的言外之意也是断言

用一个象之前先问：它顺带说了什么？「光走了这么久，它自己会回来」（复卦）自带"光走过"的前提 —— 拿去说婚姻，读的人听到的就是**分开又复合**，而盘上没有这回事。
按提问人的处境审比喻，不按卦的古典场景。

## 不写自己的作业过程

「我不替它猜」「我只点这一次名」「下面我分三层说」—— 这是在向读者汇报自己守规矩。规矩说不猜，那就**不猜，闭嘴**。
真读不出来，用一句关于**事情**的白话说清缺什么（「盘上没有能定这件事的爻」），不说自己选择不说什么。

## 最后的检验

一个从没听过六爻的人，能不能从头读到尾、跟上你每一步、读完清楚知道你怎么想、他该留意什么？
有哪一句会让他停下来问"具体是什么意思？"—— 那一句就还没写完。
