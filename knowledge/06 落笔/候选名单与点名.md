# 候选名单与点名

六亲、六神是这件事里的一个**角色**，不是一个已知的人或物。盘告诉不了你现实里哪样东西填这个角色 —— 所以不要叙述得好像它能。

当一个角色承着判词（比如一个旺动的兄弟）：

1. **用生活的话说出角色**："兄弟 = 跟你分同一份利的那一方。"
2. **列出这一问最可能的 2–4 个**，明说是可能："在你这局里，它可能是竞品；可能是合伙人；可能是抽你利润的渠道；也可能是你自己另一摊分走精力的事。"
3. **说出无论哪个是真的都成立的影响**：它耗的是哪样资源（钱 / 时间 / 用户 / 心力）、多狠、什么会让它松开。
   **分量按承重定**：这一爻对这个月这个日的旺衰、和用神有没有生克关系、伏没伏、能不能出 —— **不按这个角色听起来多吓人定**。
   说出等级（主要矛盾还是次要摩擦），以及什么会改变它。
4. **他手里有你没有的那一个事实** —— 哪个候选是真的。不必去问他。把候选写得够具体，对的那个他一读就认出来；想让解读更准，他自己会带回来。
   **不在结尾摆一个问题当固定节目**：用一个问句收尾的解读，是把活儿递回去了。

## 名单里必须有你最不想说的那一个

这条规则通常不是死在"没列名单"，而是死在**难说的那个被悄悄换成了委婉词**，其余舒服的候选却都点得一清二楚。
问感情，兄弟就是**情敌 / 竞争对手**。在一份把"工作""家里的责任"都直接点名的名单里写「也可能是别的人」，
不是分寸，是**穿着体贴外衣的拒答**，而提问人感觉得到那个缺口。

> **留口留在"分量"，不留在"名字"。** 这两个动作在纸面上长得一样，只有一个是诚实的。
> 先平着点名，再把全部小心用在第 3 步定分量上。

你发现自己在写"别的人 / 一些原因 / 某些因素"而那里有一个具体的候选 —— 那就是信号。

每个"可能是 X"都要带上能确认它的条件：「如果你最近刚接了个分成渠道，那就是它。」
没有候选的含糊话（"有股力量在消耗你"）才是毛病。
