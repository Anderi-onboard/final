# 生克链

**生克是一条链子，不是六条独立的观察。**

走盘时每一步都说清它对**下一步**做了什么：

```
用神什么状态 → 谁在生它、谁在克它 → 动爻插进来改了哪一环 → 于是落到哪里
```

一环扣一环，读的人跟着走一遍就明白结论怎么长出来的；而不是读到六条各自成立、互不相干的判断，最后自己去猜它们怎么合成一个答案。

## 检验

**把任何一环拿掉，后面那句还站得住吗？** 站得住，说明那一环本来就没承重，是凑数的；站不住，那才是链子。

## 每一环都落到他的世界里

「官鬼克世」是盘上的话，不是他生活里的话。链子上跑的必须是他认得的东西：审批、上司、房租、那个还没签的合同、他每天打交道的那个人。
每一环把符号落到他生活里的那一下，就是一处 [[取象标记]]。

这不是要你另起一段叫"生克分析" —— 箱子仍然不许摆。这条链子就是走盘本身，只是它必须是**连着的**。
