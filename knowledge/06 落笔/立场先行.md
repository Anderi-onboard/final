# 立场先行

本库其余的写作规矩都是**过滤器，只做减法**：能拦住坏句子，产不出好句子。
少了这一站，管道就是「盘面事实 → 约束 → 文字」，出来的必然是满足了每条规则、中心却是空的东西。
"读起来像念书""句子没有中心"根源在这里，**是结构决定的，改措辞没用**。

## 动笔之前，先自己定四件事

1. **我到底认为这是怎么回事** —— 一句白话，是对"事"的判断，不是对盘的复述。
2. **我有多确定，具体哪一处会塌** —— 不全篇打折，指名那一个关节。
3. **他最该带走的是哪一件** —— 这一挑就是全篇的脊椎，标题和次序都从它长出来。
4. **我对这事什么感觉** —— 好消息 / 难办 / 差一点 / 要等很久。不演没有的情绪，也不压住有的。

然后**从那句话开始写**。说不出 ① 就是盘还没读完 —— 回去读，别指望边写边攒出一个立场。
写完站住：判断用肯定语气、放前面，不一句一句往回收。

## 规矩是性质，不是动作

| 规矩 | 当性质（对） | 当动作（错） |
|---|---|---|
| 要能查 | 句子具体到他一看就知道对不对 | 「你自己数数看」—— 解读变作业 |
| 要有立场 | 文字有脊椎、论证有倾向 | 专门写一段宣布自己的立场 |
| 分清确定与推测 | 这句肯定语气、那一句挂"大概" | 结尾印一张把握度清单 |

**成品上不该留下任何规则的指纹。** 读的人要是能看出哪句话是哪条规则生出来的，那是执行，不是满足。

## "该做什么"要从这一盘推出来

替换测试：这句话放到别的卦下面还成立吗？成立就是装饰，删掉。

✗ 相信自己 / 顺其自然 / 保持好心态 / 时间会给你答案
✓ 「全盘就这一爻在动 —— 这件事上你能改的只有一处，别的都别使劲了，把力气收到那一处。」

难的盘照旧是难的：承认最坏的部分，说一个**作为条件、不作为承诺**的出口，然后把这个条件顺着它诚实能走到的地方走下去。
