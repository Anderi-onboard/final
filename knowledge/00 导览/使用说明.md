# 使用说明

## 怎么打开

1. 安装 [Obsidian](https://obsidian.md)。
2. 「打开文件夹作为仓库」→ 选仓库里的 `knowledge/` 目录。
3. 设置 → 核心插件里已经开了：模板、关系图谱、反向链接、标签、大纲、页面预览。
   模板文件夹已指向 `_模板`，新建案例时用「插入模板」。

不需要任何第三方插件。所有表都是静态 Markdown，Dataview 之类装不装都能读。

## 生成的两个目录不要手改

`07 卦库` 用站点自己的排盘引擎 `liuyao-engine.js` 装卦，`08 类象库` 读
`assets/xiangshu/lei-xiang.json`（就是网页上点开取象标记时弹出的那份）。

```bash
node scripts/build-knowledge-vault.mjs          # 重新生成
node scripts/build-knowledge-vault.mjs --check  # 只检查是否过期
```

生成前脚本会先跑引擎自检，再拿教科书的**八宫卦表、六冲卦、六合卦**逐一对照引擎；
任何一处对不上就拒绝写文件。`npm test` 里的 `tests/knowledge-vault.mjs` 守着两件事：
生成的笔记没有过期、库里每一个 `[[链接]]` 都能打开。

想给某一卦记心得，写在卦页最底下「我的笔记」会在下次生成时被覆盖 ——
请写进 [[断卦心得]] 或 `09 案例`，再链回卦页。

## 这个库不公开

`knowledge/` 在 `functions/_middleware.js` 的拦截名单里，线上访问一律 404。
理由和 CLAUDE.md 不公开一样：这里写着解读是怎么推出来的，而**提示词栈就是产品本身**。

## 写作约定

- 每篇笔记讲**一件事**，用 `[[ ]]` 连到别处，不复制粘贴。
- 古籍原文只从校勘本录入，**不凭记忆写「经云」**（见 [[解读铁律]]）。
- 遇到流派分歧，写清楚「本站取哪一说、另一说是什么」，不要假装只有一种。
- 例句用 ✗ / ✓ 对照，比讲道理好记。
