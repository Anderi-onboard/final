# 世应

- **世** = 自己：身体精神、立场、手上的资源、能做主的范围。类象 [[爻位·世爻]]。
- **应** = 对方、外界、事情的落点。类象 [[爻位·应爻]]。
- 世应位置由八宫世系定，应永远隔世两爻。见 [[八宫与世应]]。

## 关系

| 世应 | 一般读作 |
|---|---|
| 相生、相合 | 和、顺、彼此有意 |
| 相冲、相克 | 阻、不合、有摩擦 |
| 比和 | 相近；也可能都在等对方先动 |
| 世克应 | 我主动、我占上风 |
| 应克世 | 对方主导、事压着我 |
| 应生世 | 对方帮我、事来就我 |
| 世生应 | 我出力、我付出 |

> [!warning] 同一个关系，换个问题意思就变
> **应克世**：问时机，读作事情压着他；问和合，读作她定节奏；问生意，读作对方握着筹码。
> 盘没变，变的是问题。把一种映射搬到另一种问题上，就会说出盘上没有支撑、听起来却同样有根据的话。
> 见 [[关系还不是意义]]。

## 状态

| | 读作 |
|---|---|
| 世旺 | 自己有底气、扛得住 |
| 世衰、世受克 | 力不从心、被压 |
| 世空 | 自己心不在、或无力 |
| 应空 | 对方无意、虚应、还没出现 |
| 应动 / 应化 | 对方有变数 |
| 世应之间隔着的爻（间爻） | 距离、保留、中间人或横在中间的东西 |
| [[用神|用神持世]] | 事在自己手里 |

问自己、决策、出行、总体运势，**世爻就是用神**。
