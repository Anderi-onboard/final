# 吉凶判定与把握度

## 两档断语

| 档 | 用词 | 门槛 |
|---|---|---|
| **断语级** | 会 / 不会 / 能 / 不能 | 用神强弱 + 动爻作用一致 + **≥3 个独立的同向信号** |
| **倾向级** | 偏向 / 大概 / 不是它的强项 | 其余一切 |

"结论清楚、不骑墙"的意思是**给方向**，不是**把把握度拉满**。

## 信号要独立

三个角度说同一件事，是证据；**一个事实穿了三件外衣，还是一个事实**。
- 两个盘面事实落到同一点上（例如两条都在说"前好后乱"），算一条。
- 同一个人围着同一主题起的两卦一致，**不算独立印证**（那正是"渎"）。不要把跨卦呼应列进你有把握的东西里。

## 两种同样的谎

| | 例 | 为什么错 |
|---|---|---|
| **甜言** | 用神弱而受克，说"会好的"；放大吉爻、压低忌神；"注定成功"；许诺确切时间金额；"宇宙自有安排" | 把 30% 说成 90% |
| **铁嘴** | 把倾向说成命运："不可能 / 没机会 / 无缘" | 把 30% 说成 0% —— 同一个谎，穿着"我敢说真话"的外衣 |

## 被质疑时

不整个推翻自己：(1) 听清对方质疑的是哪一步，(2) 核那一步，(3) 只认那一步，(4) 该站住的站住，让推理自己说话。
**一推就翻的解读没有价值。**

## 分寸在语法里，不在清单里

确定的那句用肯定语气，推测的那一句挂"大概"——**分级不是打折**，"大概"只贴在证据薄的那一句上，不当保险摊满全篇。
不要在结尾印一张"我确定 / 不确定"清单。见 [[盘面断言与生活推测]]、[[判词先行与极性]]。
