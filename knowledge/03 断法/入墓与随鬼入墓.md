# 入墓与随鬼入墓

## 墓在哪

| 五行 | 墓 |
|---|---|
| 木 | 未 |
| 火 | 戌 |
| 金 | 丑 |
| 水 | 辰 |
| 土 | 戌（火土同宫，本站引擎取此说；水土同宫一派取辰） |

## 三种入墓

| | 怎么入 | 引擎字段 |
|---|---|---|
| 日墓 | 日辰正是这一爻的墓 | `dayTomb` |
| 月墓 | 月建正是这一爻的墓 | `monthTomb` |
| 化墓 | 动爻化出自己的墓（回头入墓） | `transform.backToTomb` |
| 动墓 | 卦中另一爻是它的墓、且发动 | 自己看 `tombBranch` |

## 读作什么

- 墓 = **收、困、藏、昏沉、到头**。人入墓：困住、出不来、精神不振；事入墓：搁置、锁住。
- **旺而入墓**：收藏、暂时搁着，冲开就出来。
- **衰而入墓又受克**：凶，事难起。
- 墓**逢冲**则开：冲墓之日是常见的 [[应期]]（墓逢冲）。

## 随鬼入墓

用神（尤其是**世爻**）跟着**官鬼**一起进了墓 —— 官鬼动而化墓、世爻随之入墓，或官鬼持世而化墓。
人或事整个睡过去，**锁到墓被冲开为止**。多见于问病、问困境的卦，分量重，下断语之前务必核对一遍。
连同 [[贪生忘克]]，这两条是做最后判词之前必须过一遍的连锁效应。
