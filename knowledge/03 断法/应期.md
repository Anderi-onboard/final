# 应期

**问"什么时候"，应期就是主菜**：判词里必须给一个和问题尺度相符的具体时间锚。
没问时间的人，不要塞应期给他。

## 第一步：定尺度（先于一切）

| 问题里说 | 尺度 | 锚 |
|---|---|---|
| 最近、这周、这个月 | 近（日 / 周） | 地支**日**的具体公历日期 |
| 今年、半年内 | 中（月） | 地支**月**的窗口 |
| 以后、将来、这辈子、毕业以后 | 远（年，甚至几十年） | 地支**年** → 公历年 |
| X 之前（毕业前、年底前、30 岁前） | **有硬右边界的窗口** | 先断窗口内成不成；若落在窗口之后，一口气说出来 |

> [!danger] 尺度错了 = 答非所问
> 问"我以后能不能住进那里"，答"现在行不通"或给一个这个月的日子，都是在回答一个没人问的问题。
> 最多用一句话把现在放成起点：「眼下离它还远，这不奇怪，你才大一。」

## 第二步：从盘上找触发点

事情落地，是决定性的那一爻遇到：

| 爻的状态 | 应在 |
|---|---|
| 旺相、发动 | **值日**（逢本支之日）、或逢合 |
| 太旺 | 逢墓、逢冲（收得住、冲得开） |
| 休囚 | 逢**生扶**、逢**旺**之时 |
| 旬空（假空） | **填实**（逢本支）· **冲空**（逢冲）· 出旬 |
| 入墓 | **墓逢冲** |
| 静 | 逢冲（冲起） |
| 动而被合住 | **合处逢冲** |
| 被冲散 | **冲中逢合** |
| 半合缺一支 | 那一支到来之时（局成） |
| 伏神 | 出伏之时（飞神被冲、伏神得生旺） |
| 月破而有气 | 出月、逢合、填实 |

## 第三步：同一个地支，三种尺度

同一个触发在每个尺度上都会发生，只有提问人知道哪一个对得上他的生活：

1. **从时辰 → 日 → 月 → 年**，把盘支持的每个尺度都写出来，说清"如果是这一档，它看起来会是什么样"；
2. 说出你认为是哪一档、为什么；
3. 每档给 **2–3 个最近的具体可能**（干支循环会重复）；
4. 盘上解析不了某一档，就说这一档读不出，**不要为了填格子编一个日子**。

**分层应期**：渐进型的卦有"初见端倪"和"全面落地"两个时间点，远期问题上可能隔好几年 —— 两个都说。

**用神没有被触发**：就说"这个尺度上还没有清楚的时间信号"，不要拿一个近期日子顶替。

## 第四步：落到公历

西方读者拿着"寅月"什么也做不了。**地支留作风味，公历日期承载意思**：

- 地支日每 **12 天**一轮：从起卦日的日支往后数。
- 地支月按节气：寅月 ≈ 2/4–3/5 …… 见 [[天干地支|月建表]]。
- 地支年：2026 丙午，2027 丁未，2028 戊申，2029 己酉，2030 庚戌，2031 辛亥，2032 壬子，2033 癸丑，2034 甲寅……（12 年一轮）

例见 [[示例·一次面试能不能拿到 offer]] —— 起卦日 丁卯，逢子日（10/29）冲开合、逢寅日（10/31）火局成。

> 应期是**阶段判断，不是日历保证**。说一次，然后给足。
