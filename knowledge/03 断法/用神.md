# 用神

用神 = 代表所问之事的那一爻。**断卦的第一步，也是能不能读的唯一判据**：定得出用神，就能读。

## 取用表

| 问什么 | 用神 | 另看 |
|---|---|---|
| 求财、生意、投资方向 | 妻财 | 世应；兄弟（劫财） |
| 工作、功名、升迁、竞争对手 | 官鬼 | 世爻；父母（文书） |
| 考试、学业、文书合同、房屋车船、长辈、庇护 | 父母 | 官鬼（考试也看功名） |
| 子女、宠物、下属、消遣、医药；**解除约束** | 子孙 | |
| 兄弟姐妹、朋友、同行、分利者 | 兄弟 | |
| 婚恋对象、配偶 | 男问 **妻财**，女问 **官鬼** | 对方态度看**应爻** |
| 房事、和合、情欲 | 子孙（欢愉本身） | 世应生克（谁主动）、玄武（私密） |
| 长相、性情、物象 | 用神所临之爻的八卦类象 · 五行 · 六神 | 射覆同此 |
| 自己、决策、出行、总体运势 | **世爻** | |
| 应期 | 用神的旺衰、填实、逢冲、逢合、入墓、出空 | 见 [[应期]] |
| 数量 | 用神地支的河图数配旺衰 | 不是数爻的个数，见 [[数量与河图数]] |
| 疾病 | 官鬼（病）· 子孙（药）· 世爻（身） | 只说趋势，见 [[疾病]] |

> 站点 `liuyao-ai.js` 里的 `CATEGORY_YONGSHEN` 只是**先验**（例如婚恋默认官鬼）—— 读卦时要按问题的措辞改。

## 万能取用法：任何问题都能落到用神

1. **剥出主体**：问题到底在问哪件东西。
2. **定它对提问人的角色**：同一件东西在不同问题里是不同的六亲。房子对买房的人是父母，对卖房赚钱的人是妻财。
3. **把问题翻成卦上的动作**：成不成 = 旺衰；有没有 = 空墓伏；什么时候 = 应期；在哪 = 方位；什么样 = 取象。
4. **兜底**：六神 + 卦名 + 八卦类象。

## 真没有用神的，只有这几类

- 具体数字和专名：电话、密码、彩票号、精确到元的金额、人名、门牌号 —— **象没有这种分辨率**。
- 超出方法精度的清单：具体行为的目录、年尺度问题精确到小时。方法给性质和方向，不给目录。
- 与卦无关的事实查询：某只股票现价、某条法律怎么写 —— 那是查资料。

碰到这些，直说"象没有这个分辨率"，然后去读问题里**有用神的那部分** —— 几乎每个这类问题都有。

> [!danger] 两条规矩
> 1. **不拿"这个读不出来"当推辞。** 心里不舒服不等于读不了。真该拒，理由在 [[解读铁律]] 的优先级里，说那个真理由。
> 2. **没有用神的不读。** 定出用神才有资格下断语；没有用神的"判断"是没有地基的漂亮话。

## 用神两现

用神出现两次，问题是**用哪一爻**，不是"有两个"（两个父母爻不等于两套房，见 [[计数不是计物]]）。取法：

1. 取**发动**的那一爻；
2. 都静，取**临月建或日辰**、或旺相的那一爻；
3. 再不行，取**持世或近世**的那一爻；
4. 一空一不空，取不空的（空的那个待出空再论）。

取了哪一爻、为什么，要说出来；另一爻是背景，不是第二件东西。

## 用神持世

用神就在世爻上，通常是好事：**这件事在你自己手里**。
但如果问题问的正是**世与用神之间的关系**（她怎么看他、谁追谁），而两者是同一爻 ——
关系要两爻才有，这一卦只有一爻。直说，另起一卦；硬描述一段盘上不存在的关系是编造。

## 用神弱 ≠ 读不了

不上卦而有伏神、旬空、入墓、被克 —— **能读，读得软一点**。说出折扣，说一次。
伏而不空 比 明现 弱，伏而又空 更弱。这是把握度的档位，从来不是拒答的理由。见 [[伏神与飞神]]。
