# 旺衰

一爻有没有力，看三样：**月建、日辰、卦中动爻**。

## 月建：季节，管一个月

- 爻的五行对月建：旺、相为有气；休、囚、死为无气。表见 [[五行生克]]。
- 爻的地支就是月建 → **临月建**，最旺（这一爻"当令"）。
- 月建生爻、与爻比和 → 有气；月建克爻 → 受制。
- 月建冲爻且爻无气 → [[月破]]。

## 日辰：当下，最有决定力

日辰对爻的生、克、冲、合都算数，而且**比月建更直接**：

| 日辰对爻 | 静爻 | 动爻 |
|---|---|---|
| 生 / 比和 / 临日 | 有气 | 有气，力更足 |
| 克 | 受伤 | 受伤 |
| 冲 | 旺相 → [[暗动与日破|暗动]]；休囚 → 日破 | 冲散其力（动爻逢冲为"冲散"），或冲开合住 |
| 合 | 合起（有气则吉） | 合住，动不起来，待冲 |
| 为其墓 | 日墓，见 [[入墓与随鬼入墓]] | 同 |

> 引擎对每一爻都标好了：`dayGenerates / dayControls / dayClash / dayCombine / dayTomb`，月建同理。

## 卦中动爻

- 动爻生扶用神 → 加力；动爻克用神 → 减力。
- 变爻回头生 / 回头克本爻，见 [[动爻与变爻]]。

## 总结

**旺 + 得生扶 + 不空不破 → 吉；休囚 + 受克 + 空破墓 → 凶。**

两个细处：
- **休囚不等于死定。** 休囚而得日生、得动爻生，照样起得来；"休囚得生"是很多"能成，但要等"的来源。
- **太旺也是一种状态。** 旺极之爻反而要等**逢墓、逢冲**才应（收得住、冲得开）。见 [[应期]]。

> [!warning] 旺衰只说现在
> 月建是起卦这个月的月建。拿它去判一个盘没见过的月份是越界 —— 弱只限制一件事在解读里占多重，
> **永远不能拿它否认那件事发生过**。见 [[月建只管现在]]。
