# 原神 · 忌神 · 仇神

用神一定，其余各爻的立场就**按五行固定推出**（站点 `liuyao-ai.js` 的 `deriveRoles()`）：

| 角色 | 和用神的关系 | 在这件事里是 |
|---|---|---|
| **原神** | 生用神 | 源头、帮手 |
| **忌神** | 克用神 | 威胁、阻力 |
| **仇神** | 生忌神（= 克原神） | 给阻力加油的 |
| **泄神** | 用神所生 | 耗用神的气；但它**克忌神**，所以也护着用神 |

例：用神是火 → 原神木、忌神水、仇神金、泄神土。

## 两个决定性的问题

1. **原神在给用神供气吗？** 原神旺相、发动、化回头生 → 有源；原神休囚不动、空破、动而化退化绝 → 有名无实。
2. **忌神在主动克用神吗？** 忌神发动且有气 → 真威胁；忌神静而休囚、旬空、月破 → 摆设。

**这两问的答案，对结论的决定力比任何单独一爻都大。**

## 组合

| 情形 | 读作 |
|---|---|
| 原神动生用神，忌神静弱 | 顺 |
| 忌神动克用神，原神不动 | 难 |
| 忌神、仇神同动 | 双重压力 |
| **忌神、原神同动** | 忌生原、原生用，**连续相生，反而吉**（见 [[贪生忘克]]） |
| 原神化忌神 | 帮手变了卦：先好后坏 |
| 忌神化原神 / 化用神 | 威胁转弱 / 险中得助 |
| 泄神旺动 | 克住忌神，同时耗用神的气 —— 看用神本身扛不扛得住 |

> [!note] 先排立场，再谈生克
> 没有这一步，"X 克 Y" 只是两个地支之间的一句语法，不带任何吉凶。见 [[生克没有善恶]]。
