# 动爻与变爻

## 规则

1. **动爻能生克别爻**；静爻一般不能去生克动爻。
2. **变爻只回头作用于它自己的那一爻**，不去生克卦中其他爻。
3. 日辰、月建对动爻、变爻都有生克冲合。

## 变爻对本爻：九种关系

| 关系 | 怎么认 | 读作 | 引擎字段 |
|---|---|---|---|
| **回头生** | 变爻五行生本爻 | 越动越有力，有接济 | `feedsBen` |
| **回头克** | 变爻五行克本爻 | 自伤，动了反被拖累 | `controlsBen` |
| **化进神** | 化出同五行的下一位 | 势头往上走 | `jinTui = 进神` |
| **化退神** | 化出同五行的上一位 | 窗口在关，后劲不足 | `jinTui = 退神` |
| **化空** | 变爻旬空 | 动出来是空的 | `backToVoid` |
| **化墓** | 变爻是本爻之墓 | 动着动着收住了、困住了 | `backToTomb` |
| **化绝** | 变爻是本爻之绝 | 中途断根 | 比对 `deadBranch` |
| **化合** | 变爻与本爻六合 | 有牵连、被绊住；动得慢，待冲开 | `combineBen` |
| **化冲** | 变爻与本爻六冲 | 来回、反复（爻上的反吟） | `clashBen` |

进神：寅→卯、巳→午、申→酉、亥→子，以及 **丑→辰、辰→未、未→戌、戌→丑**。退神反之。

> [!warning] 引擎只标前四组进退神
> 土的四组（丑辰未戌）引擎不标，见 [[引擎与断法对照]]。土爻动化，自己核对一遍。

## 用神被动变改了什么

| 用神 | 读作 |
|---|---|
| 化进神 | 有势头 |
| 化退神 | 窗口在关 |
| 化回头生 | 越来越好 |
| 化回头克 | 自己动出问题 |
| 化空 / 化墓 / 化绝 | 中途没了 |

## 角色转化

| 转化 | 读作 |
|---|---|
| 忌神 → 化出用神 | 险中得助，跨过了阻碍 |
| 忌神 → 化出原神 | 威胁转弱，往好里转 |
| 原神 → 化出忌神 | 帮手蒸发，先好后坏 |
| 用神 → 化空墓绝 | 半路折了 |

## 整卦的变

- 本卦 = 现在，变卦 = 去向。变卦比本卦好，是在打开；更差，是在收。见 [[Stria五行速断]]。
- 变出 [[六冲卦]] / [[六合卦]]、出现 [[伏吟与反吟]]，都是整卦层面的信号。
