# 贪生忘克

**要克用神的那一爻，自己正在被第三爻生 —— 它贪着这份生，就忘了去克。** 威胁被化解了。

最常见的形状是 **忌神与原神同动**：

```
仇/忌神 ──生──▶ 原神 ──生──▶ 用神
```

忌神本该克用神，但它和原神一起动，忌神去生原神、原神去生用神，一路接续相生 —— **反而吉**。

## 同类

| 名 | 形状 | 读作 |
|---|---|---|
| 贪生忘克 | 克者另有所生 | 威胁不落到用神上 |
| 贪合忘冲 | 要冲的那一爻被别的爻合住 | 冲不出来 |
| 贪合忘生 / 忘克 | 被合住了，生克都顾不上 | 帮手或威胁都暂时失效 |
| 连续相生 | 一路相生到用神 | 有源有续 |

和 [[入墓与随鬼入墓|随鬼入墓]] 一起，是写最后判词之前必须核对的两条连锁效应：
它们能把单看每一爻得出的结论**整个翻过来**。
