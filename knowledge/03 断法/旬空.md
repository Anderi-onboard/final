# 旬空

## 怎么算

起卦那天的日柱落在哪一旬，那一旬没轮到的两个地支就是空亡。

| 日柱所在旬 | 空 |
|---|---|
| 甲子 → 癸酉 | 戌 亥 |
| 甲戌 → 癸未 | 申 酉 |
| 甲申 → 癸巳 | 午 未 |
| 甲午 → 癸卯 | 辰 巳 |
| 甲辰 → 癸丑 | 寅 卯 |
| 甲寅 → 癸亥 | 子 丑 |

## 先分真假，再开口

> **旺不为空，动不为空，有生扶不为空。**

| | 条件 | 读作 | 什么时候起作用 |
|---|---|---|---|
| **假空** | 空而旺相、发动、得日月生扶、入局得助 | **还没到**，不是没有 | 出空（过了这一旬）· 填实（逢本支之日）· 冲空（逢冲之日）—— 要说是哪一种，给出时间 |
| **真空** | 空而休囚死，又无生扶 | **没有**，就说没有 | 不会来 |

- 假空的例子：父母空 = 打扮这件事关着而不是缺；子孙空 = 兴致睡着；妻财空 = 她还没出现。
- **两头都会错**：把假空读成没有，是把只是来早了的东西一笔勾销；把真空读成"还没到"，是卖给人一场等不到头的等待 —— 软一点的谎还是谎。

## 把空带进结论

一爻空了，**剩下的盘还能量什么**？例：代表外表的那一爻空着，世应比和就不是在量"她好不好看"，而是在量一件根本没打开的事。
不问这一句，结论就在回答一个盘没问的问题。

## 化空

动爻化出的地支落在旬空（引擎 `transform.backToVoid`）：动了，但动出来的是空的 —— 用神化空，中途落空；忌神化空，威胁落空。

## 落地

"自己还没到位"是半句话。写全：**什么**没到位（钱？人？时机？决心？），什么算到位。见 [[白话与判词自足]]。
