# 独发与独静

先数动爻，再决定读法 —— 而且在解读里说清楚这一卦是哪一种。

| 动爻数 | 名 | 读法 |
|---|---|---|
| 1 | **独发** | 整卦的话集中在这一爻：它是什么六亲、对用神做什么、化成了什么。 |
| 0 | **独静**（静卦） | 没有变化可依：分量全落在**用神本身的旺衰 + 世应 + 日月**上，别忘了被日冲而 [[暗动与日破|暗动]] 的爻。 |
| 2–3 | 多动 | 逐个看对用神的生克，再看它们彼此之间（原忌同动、忌仇同动）。见 [[原神忌神仇神]]。 |
| 4–6 | 乱动 | 事杂、头绪多；仍以用神为纲，不要被动爻数量带着走。 |

## 由这一点推出的"该做什么"

动爻的个数本身就说了他能用力的地方有几处：

- ✓「全盘就这一爻在动 —— 这件事上你能改的只有一处，别的都别使劲了，把力气收到那一处。」
- ✓ 静卦：「没有哪一处在动，这件事现在不是靠推的 —— 是看它本来就有多少底子。」

这类话必须**随盘而变**：换一卦它就该不一样。换哪一卦都成立的，是格言，删掉。见 [[立场先行]]。
