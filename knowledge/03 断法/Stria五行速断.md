# Stria 五行速断

站点的轻量读法。和 Sortis 同一个声音，**深度不同，形状相同**：不碰纳甲的深层机关（伏神出伏、三合局、贪生忘克、细的应期链）。
盘上就算给了这些，最多一个分句带过。

## 五步

1. **吉凶字**（卦辞 / 爻辞里的 吉 · 凶 · 无咎 · 悔 · 吝 · 厉 · 利）：先**照字面**读 —— 凶就是凶，不是"一个挑战"。这是底色。
   原文要来自校勘本或后端，**不凭记忆**。
2. **内外卦关系**：上生下 / 下生上 → 顺、有支持；上克下 / 下克上 → 紧、有摩擦；同卦 → 加强。两半是合作还是冲突。
3. **互卦**（二三四 + 三四五）：表面下的结构，提问人没说出来的那部分，必须经过的过程。见 [[互卦·错卦·综卦]]。
4. **变卦方向**（本 → 之）：变卦比本卦吉，是在打开（如走向泰）；更凶，是在收。整体是进是退。
5. **动爻位置**：当位？得中？有应？中 + 正 + 应 = 强；不当位 + 无应 = 孤立。见 [[爻位]]。

> 注：站点的 Stria 起卦会把动爻抹平，所以线上 Stria 读的是本卦；第 4、5 步用在你自己手摇、带动爻的卦上。

## 结构

**现在（本卦）→ 过程（互卦）→ 方向（变卦）**

## 篇幅

开篇约 1500–2500 字。比 Sortis 紧，是因为看的东西少，**从来不是因为在意得少**。
