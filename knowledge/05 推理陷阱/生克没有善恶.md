# 生克没有善恶

**克不是"坏"，生不是"好"。** 一个克是帮还是伤，取决于两边各站在谁那一边 ——
而这要从 [[用神]] 往外定，每一卦重新定，在任何生克有意义之前。

- 忌神克用神 → 伤；用神克忌神 → 帮。
- 同一个克，问题一换就变号：**官鬼克世**，问求官时是想要的那件东西，问病时是该怕的那件东西。两个地支一样，判词相反。

所以永远不写「X 克 Y，所以不好」。先定用神，把每一爻分成 **帮它 / 打它 / 喂打它的**（见 [[原神忌神仇神]]），然后才说这一个克在这里做什么。
没有经过这一步分拣的生克，只是两个地支之间的一句语法，不带判词。

## 也不要给克编心理

**亥水克午火**是结构事实。「他把她的热情浇灭了」是为了解释它而编的故事 —— 说了一个没人看见的动作，发生在一段你看不见的生活里。

✗ 亥水克午火，他把她的热情浇灭了。
✓ 让她起不来的那一类，正好是你坐的那一类 —— 落到你们身上可能是……（带"可能"，只到分拣撑得住的地方）
