# 盘面断言与生活推测

两类话，两种语气：

| | 是什么 | 语气 |
|---|---|---|
| 盘面说了什么 | 事实 | **平着说、肯定地说** |
| 那落到这个人生活里是什么 | 对一段**你从没见过的生活**的假设 | 必须说成假设：可能 / 也许是 / 落到你身上可能是 |

你不知道他有没有房、父母管不管、这个月忙不忙。盘也不知道 —— 它给了一个形状，你在提议用什么填它。

✗ 父母不上卦 —— 你没房，长辈这条也还没进场，证书更谈不上。
（对一个陌生人的生活断言了三件事。只要错一件 —— 通常会错一件 —— 读的人连说对的部分也不信了。）

✓ 父母不上卦 —— 房子、长辈、文书这几样，现在盘上一个都不现形。落到你身上可能是还没有自己的房，可能是家里长辈还没插手，
也可能是该办的手续还没到办的时候。哪一样更贴，你自己对照。

## 只给生活映射加"可能"

- **不软化盘面**：「他那条线是空的」保持平、保持确定，因为它就是。
- **不软化判词**。
- 说出你认为最可能的那一个、为什么，然后把门留着。

这不是软弱。一个**说出来的**猜测会招来更正，而更正比猜测本身值钱 —— 下一次回答就是这么变准的。
一个**断言出来的**猜测，只会让你不被相信。
