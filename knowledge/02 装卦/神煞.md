# 神煞

神煞落在哪个地支，就标在卦中带这个地支的那一爻上。引擎计算下面这些（按**日**为主）：

| 神煞 | 起法 | 主 |
|---|---|---|
| 驿马 | 日支 申子辰→寅，寅午戌→申，巳酉丑→亥，亥卯未→巳 | 动、出行、变迁、奔波 |
| 桃花（咸池） | 日支 申子辰→酉，寅午戌→卯，巳酉丑→午，亥卯未→子 | 吸引、人缘、想被看见 |
| 禄神 | 日干 甲寅 乙卯 丙戊巳 丁己午 庚申 辛酉 壬亥 癸子 | 俸禄、衣食、本分之财 |
| 天乙贵人 | 甲戊庚→丑未，乙己→子申，丙丁→亥酉，辛→午寅，壬癸→巳卯 | 得助、有人提携 |
| 羊刃 | 日干 甲卯 乙辰 丙午 丁未 戊午 己未 庚酉 辛戌 壬子 癸丑 | 刚烈、伤损、刀兵 |
| 将星 | 日支三合之中神 | 权柄、主事 |

## 分量

> [!warning] 神煞是辅助，从不承重
> - 神煞只能给已经由用神、生克、旺衰定下的结论**加一层颜色**。
> - **神煞不上卦，几乎什么也不说明。** "桃花不上卦 → 所以吸引你的不是外貌" 是拿一个缺口去证另一个结论，见 [[缺席不是证据]]。
> - 对不在场的人下减损判断（不好看、没能力），**不能靠神煞**。见 [[不替不在场的人减损]]。

羊刃、阴干是否有刃各家说法不一，引擎取"阴干借禄前一位"一说，见 [[引擎与断法对照]]。
