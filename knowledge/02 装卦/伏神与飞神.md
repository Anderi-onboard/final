# 伏神与飞神

## 什么时候有伏神

一卦六爻配下来，五类六亲不一定齐。**缺的那一类不是没有，是伏着**：
到本宫的八纯卦里，找同一爻位上那个六亲 —— 它就是**伏神**；本卦那一爻是压在它上面的**飞神**。

例：[[天风姤]]（乾宫）没有妻财。乾为天二爻是甲寅木妻财，于是**妻财寅木伏在姤二爻亥水子孙之下**。

> 64 卦里 44 卦有伏神。伏神是常态，不是稀罕事。

## 出伏还是伏而不出

用神（或原神）伏着时，**这一条就是答案的一半**，不能只点名不判断。

| 能出（潜在、够得着，多半要晚一点） | 出不来（现在不在、够不着） |
|---|---|
| 伏神旺相，或得日月生扶 | 伏神休囚无气 |
| 飞神生伏神 | 飞神克伏神（伏受制） |
| 伏神克飞神 | 伏神生飞神（泄气给飞神） |
| 飞神旬空、月破、休囚 | 伏神自己旬空、月破、入墓、绝 |
| 飞神发动，或被日辰冲开 | 飞神旺而静，牢牢压住 |
| 飞神发动**化出的正是伏着的那个地支** —— 那就是它出来 | |

- **伏而不空 比 明现 弱一档，伏而又空 再弱一档。** 这是把握度的折扣，不是"读不了"。见 [[用神]]。
- 用神伏而不出，主这件东西现在不在、够不着；能出，主潜在、要等，出伏之时就是 [[应期]] 的候选。
- **原神伏着同样要判。** 用神明明在卦上，唯一能生它的原神却伏着 —— 那它有没有来源，就看原神出不出伏。
  站点的引擎会把所有伏神都报出来，就是为了这种情形（`liuyao-ai.js` 里有一段实测记录）。
