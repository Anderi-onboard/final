# 八宫与世应

## 八宫怎么来

每宫以八纯卦为首，**从下往上一爻一爻变**：

| 世系 | 怎么变 | 世在 | 应在 |
|---|---|---|---|
| 本宫（八纯） | 不变 | 上爻 | 三爻 |
| 一世 | 变初爻 | 初爻 | 四爻 |
| 二世 | 再变二爻 | 二爻 | 五爻 |
| 三世 | 再变三爻 | 三爻 | 上爻 |
| 四世 | 再变四爻 | 四爻 | 初爻 |
| 五世 | 再变五爻 | 五爻 | 二爻 |
| 游魂 | 五世卦的四爻变回 | 四爻 | 初爻 |
| 归魂 | 游魂卦的内卦全变回本宫 | 三爻 | 上爻 |

**应永远和世隔两爻**（世 ± 3）。

寻世口诀（拿到任何一卦，不查表就能定宫和世）：
> 天同二世天变五，地同四世地变初，本宫六世三世异，人同游魂人变归。

把内外两个经卦**逐位对比**：地位 = 初爻对四爻，人位 = 二爻对五爻，天位 = 三爻对上爻。

| 对比结果 | 世系 | 世在 |
|---|---|---|
| 三位全同 | 本宫 | 六 |
| 只有天位同 | 二世 | 二 |
| 只有天位不同 | 五世 | 五 |
| 只有地位同 | 四世 | 四 |
| 只有地位不同 | 一世 | 初 |
| 三位全不同 | 三世 | 三 |
| 只有人位同 | 游魂 | 四 |
| 只有人位不同 | 归魂 | 三 |

定宫：
> 一二三六外卦宫，四五游魂内变更，归魂内卦是本宫。

即一世、二世、三世、本宫看**外卦**；四世、五世、游魂把**内卦阴阳全反**；归魂就是**内卦**。

例：[[天风姤]] 内巽外乾，只有地位（初阴对四阳）不同 → 一世，世在初；一世看外卦 → 乾宫。

口诀记不住时，**直接查 [[六十四卦索引]] 的八宫卦表**，引擎就是按上面那张变爻表生成的，生成时还和教科书逐卦对过。

## 宫的五行定六亲

| 宫 | 五行 | 宫 | 五行 |
|---|---|---|---|
| 乾、兑 | 金 | 震、巽 | 木 |
| 离 | 火 | 坎 | 水 |
| 艮、坤 | 土 | | |

一卦每一爻的 [[六亲]]，是这一爻地支的五行**对宫五行**的关系，不是对本爻所在的上卦或下卦。

## 游魂与归魂

- **游魂卦**：心神不定、在外未归、事多反复、想走。
- **归魂卦**：回到本位、归家、事情收拢，但难有远图。

它们说的是这件事的"性"，和用神旺衰是两回事，不能单凭它断成败。
