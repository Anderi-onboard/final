# 六神

## 起法（按日干，从初爻往上排）

| 日干 | 初爻起 |
|---|---|
| 甲 乙 | 青龙 |
| 丙 丁 | 朱雀 |
| 戊 | 勾陈 |
| 己 | 螣蛇 |
| 庚 辛 | 白虎 |
| 壬 癸 | 玄武 |

顺序固定：青龙 → 朱雀 → 勾陈 → 螣蛇 → 白虎 → 玄武，排满六爻。
所以六神随**起卦那天**变，[[六十四卦索引]] 的静态卦表里没有它。

## 含义

| 六神 | 英文 | 事 | 人 / 性情 | 类象 |
|---|---|---|---|---|
| 青龙 | Azure Dragon | 喜庆、婚嫁、正财、升迁 | 和善体面，有酒色之好；温柔细致 | [[六神·青龙]] |
| 朱雀 | Vermilion Bird | 口舌、文书、消息、言语 | 能说、爱讲、调笑；说出口的那一面 | [[六神·朱雀]] |
| 勾陈 | Hook Earth | 田土房产、迟滞、牵连 | 稳、慢、守旧、习惯 | [[六神·勾陈]] |
| 螣蛇 | Coiling Snake | 忧惊、怪异、虚惊、纠缠 | 想得多、放不下、幻想 | [[六神·螣蛇]] |
| 白虎 | White Tiger | 凶猛、疾病、丧伤、果决 | 直接、刚、身体性的 | [[六神·白虎]] |
| 玄武 | Dark Tortoise | 暗昧、私情、盗失、隐瞒 | 不说出口的那一面、私下的欲望 | [[六神·玄武]] |

## 用法

- **六神定"性"，不定吉凶。** 用神旺而临白虎，是事成而手段刚；用神衰而临青龙，青龙救不回来。
- 看六神**临在哪一爻**：玄武临妻财，钱的来路或去路不明；朱雀临父母，文书消息在动；白虎临官鬼动，压力来得猛。
- 只用引擎给的六神。没有盘就不谈六神。
