# 起卦

## 三钱法

1. 心里把**一件事**问清楚：问什么、问多远（这周？今年？以后？）。问题含糊，用神就取不准。
2. 三枚铜钱掷六次，从**初爻**起往上记，每次记成 6 / 7 / 8 / 9（见 [[阴阳与爻]]）。
3. 记下**起卦的时刻** —— 月建、日辰、旬空、六神都从这一刻来。
4. 装卦：[[纳甲]] → [[八宫与世应]] → [[六亲]] → [[六神]] → 找 [[伏神与飞神|伏神]]。

## 三条起卦规矩

- **一事一占。** 一卦对一件事。追问换了事（"什么时候第一次" 之后问 "什么时候谈恋爱"），就该另起一卦；硬套原卦的用神，两件事都读糊。
- **不重复问同一件事求一个想要的答案。** 同一个人围着同一件事连摇几卦，后面的卦不是"复核"，是《易》说的"渎"。两卦说法一致，**也不算独立的印证**。见 [[吉凶判定与把握度]]。
- **二选一只起一卦。** 一卦里已经同时装着两边，不为每个选项各起一卦。见 [[二选一]]。

## 站点怎么做

| | Sortis 6 | Stria 64 |
|---|---|---|
| 读什么 | 纳甲六爻全套：用神、旺衰、动变、伏神、合局、应期 | 卦辞吉凶字、内外卦五行、互卦、变卦方向、动爻位置 |
| 动爻 | 保留 | **抹平成静爻**（只读本卦，动爻无处可去） |
| 笔记 | [[断卦总纲]] | [[Stria五行速断]] |

- 铜钱由 `casting-figure.js` 的 `tossLine()` 模拟，三枚各自随机，和真掷的分布一致（每爻动的概率 1/4）。
- 排盘由 `liuyao-engine.js` 的 `computeBoard()` 完成，**解读一律以它给的盘为准，不自己重排**。见 [[引擎与断法对照]]。
- 六爻全静的概率约 18%，这时没有变卦，按 [[独发与独静|独静]] 读。
