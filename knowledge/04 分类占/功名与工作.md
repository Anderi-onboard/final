# 功名与工作

## 用神与四神

- **用神：官鬼**（职位、上司、审批那一关、对方机构）。
- 原神 **妻财**（财生官：资源、条件、薪酬那一头）；忌神 **子孙**（子孙克官：阻碍、也是想辞职想松快的心）；仇神 **兄弟**（兄弟生子孙；也是同场竞争者）。
- **父母**：官鬼生父母 —— offer、合同、文书、资质；问"能不能拿到书面通知"时看它。
- **世**：自己的状态、底气。

## 看点

| 盘面 | 读作 |
|---|---|
| 官鬼旺而生合世 | 位子向你靠 |
| 官鬼动 | 对方在推进，或压力在来 |
| 官鬼伏 / 空 | 岗位还没开出来、对方没动静 |
| 子孙动 | 卡在你和位子之间的东西；也可能是你自己想走 |
| 父母动而生世 | 文书来，书面落实 |
| 世空 | 自己心不在、或没准备好 |

"动的偏偏是官鬼 —— 所以卡你的不是能力，是**审批那一关**。" 这种句子才是落地的：说清卡在哪。

## 对现实机制做翻译

招聘有真实的、可查的机制：投递、筛选、面试、背调、审批、发 offer。把每一个承重的信号翻译成其中一个**变量**，
陈述为他处境里的一个事实；不要另附"去查什么"的作业清单。不编具体数字。见 [[学业与考试]] 的录取例子。
