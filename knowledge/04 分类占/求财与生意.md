# 求财与生意

## 用神与四神

- **用神：妻财。** 原神 子孙（财源：产品、手艺、做出来的东西）；忌神 兄弟（劫财、分利、开销）；仇神 父母（父母生兄弟；也是辛苦、文书成本）。
- 世 = 自己一方，应 = 对方 / 市场 / 交易对手。
- 官鬼：财生官，钱流向官鬼 —— 监管、税费、风险，也可能是"财能换来的位置"。

## 看点

| 盘面 | 读作 |
|---|---|
| 妻财旺相、得子孙生 | 有源有进项 |
| 妻财持世 / 生合世 | 钱到自己手里 |
| 兄弟发动 | 有人分利：竞品、合伙人、渠道抽成、你自己另一摊分精力的事 |
| 子孙伏 | 财有名而无源：看它出不出伏 |
| 财化退、化空 | 进项在收、落空 |
| 应克世 | 对方握着筹码 |

把兄弟落到实处：问买加密货币，兄弟就是**交易所的抽成和支付通道的手续费**；问开店，可能是隔壁同类店。
候选要点名，见 [[候选名单与点名]]。

## 边界

- 给**方向和性质**，不给数字、金额、具体职位名称。财务量级说**轨迹和档位**（上行 / 平 / 收缩），不说"X 万"。
- 行业方向从五行 + 六神来，不说具体公司。
- **具体投资标的拒答。** 见 [[解读铁律]]。
- "会成功"是断语级，需要 [[吉凶判定与把握度|三个以上独立信号]]；否则用倾向级。
- 破财的卦，减损的办法必须**免费、自己能做**，不指向任何付费服务或"化解"。
