# 婚恋

## 用神

- 男问：**妻财**（对方）；女问：**官鬼**（对方）。
- **应爻** = 对方的态度；**世爻** = 自己。
- 问"会不会在一起" → 用神旺衰 + 世应生合；问"她怎么看我" → 应对世；问"什么时候遇到" → [[应期]]。

## 看点

| 盘面 | 在感情里常读作 |
|---|---|
| 世应相生相合 | 彼此有意、合得来 |
| 世应冲克 | 摩擦、拉扯 |
| 应空 | 对方没心思、虚应、还没出现（先分 [[旬空|真假空]]） |
| 用神伏 | 对方不在眼前、不在场、关系不公开 |
| 男问兄弟发动 | 分走她那一份的东西：**竞争者**、朋友圈、钱的问题 |
| 女问子孙发动 | 子孙克官鬼：横在他那一头的东西 —— 孩子、玩心、她自己想要的松快 |
| 父母动 | 家里长辈、证件手续（结婚、搬家） |
| 六合卦 / 六冲卦 | 聚 / 散 |

## 规矩

- **场景想象是必须的**：具体、看得见，谁带谁、谁追谁、张力在哪。不躲在"权力动态"这种抽象词后面。
  非情欲的场景给 2–3 个日常片段，注明这是卦象延伸出来的画面，不是录像，也不锁定任何具体的人。
- **问别人，就读那个人**。"这说明你内心焦虑"不是对"她是不是 X"的回答。
- **点名要点全**：兄弟在感情里就是竞争者，不要在名单里把它换成"别的人"。见 [[候选名单与点名]]。
- **同一个事实两种讲法，取不制造败局的那种**："有人把她抢走了"和"分开之后她遇到了新人"是同一个盘面。见 [[两种讲法取不伤人的]]。
- **不替不在场的人做减损判断**（不好看、配不上）。见 [[不替不在场的人减损]]。
- **难受的结论**（分手、拒绝、单恋、背叛）：承认情绪那一拍给最多的笔墨；行动建议要从这一卦里来，不是泛泛的自我提升。
- 冲突类的卦（讼、睽）放在亲密关系里，多读作**互动的风格**（推拉、斗嘴、较劲），不是"他们总吵架"。
