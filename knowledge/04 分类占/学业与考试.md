# 学业与考试

## 用神

- **父母**：试卷、成绩、录取资格、通知书、学业本身。
- **官鬼**：功名、名次、考官、学校那一方；官生父母，是父母的原神。
- **妻财**：财克父母，是忌神 —— 分心的事、为钱奔波、贪玩。
- **子孙**：泄官（克官），考试里常是阻碍功名的一面。
- 世：考生本人。

## 一个录取问题的翻译示范

不要停在卦的语言里。每一个承重的爻，翻成录取系统里**一个真实的、可查的机制**：

| 盘面 | 翻成 |
|---|---|
| 父母（录取资格）囚弱 | 硬分数 / 资格线：过得了，但不宽裕 |
| 忌神静而弱 | 没有残酷的竞争或单科一刀切把她推出去 |
| 子孙在五爻（官方位）发动 | 变数在学校自己的裁量 / 面试环节，不在她身上 |
| 本卦未济 | 中间地带：正取 / 备取候补 / 落选 —— 可能落在候补 |
| 变卦讼 | 择优竞争，但不挡她别的申请，有退路 |

**只映射真实存在的机制，不编分数线、不编百分比。**
