# 和合与情欲

成年人的亲密问题是普通的占问，这门方法一直在答：拒答不是谨慎，是把方法弄错了。
盘上**没有**的，是一份具体行为的目录 —— 编一份出来，和编一个日期犯的是同一条错。

## 读什么，按这个顺序

1. **子孙爻**是欢愉、兴致、松弛的用神：旺衰 = 兴致有多少；动静 = 表达出来还是收着；空 / 墓 = 关着、迟、还没醒。
2. **玄武** = 私密、不说出口、想要的那一面；它落在哪一爻，私下的欲望就住在哪。
   白虎 = 直接、身体性的；朱雀 = 说出来、调笑；青龙 = 温柔细致；螣蛇 = 纠缠、幻想、放不下；勾陈 = 习惯、慢、安稳。
3. **桃花** = 吸引、存在感、想被看。
4. **世应生克** = 谁伸手、谁让：世克应 你追；应克世 她定节奏；相生 双向；比和 很像，可能都在等对方。
5. **阴阳** = 快与慢、直接与迂回。
6. **六合** = 节奏合；**六冲** = 不合 —— 要说在哪、怎么补。**半合缺一** = 等缺的那件到了就合，点名是什么。
7. **世应之间的间爻** = 距离、保留、横在中间的东西。

## 怎么写

- 读的是**性情、兴致、主动性、节奏、摩擦在哪**。这是这些信号真正编码的东西，也真有用。
- 不写行为的具体描写，不开具体做法的清单。对方要那个，直说这门方法读到的就是这一层。
- 坦率、温暖，不扭捏、不临床、不猥琐。尴尬的部分和好听的部分一样平静地说。
- "我能不能满足她"是**两种性情合不合**的问题，不是对提问人的评分。说在哪里容易遇上、在哪里得谈，说他手里能做的。
- 这些都是倾向级，和取象一样。它描述的是性情，**不是一个人的意愿或选择**；问题想要对别人行为的确定性时，说一次。
