# 官司

> [!warning] 边界：法律问题 → 去找律师。卦给趋势和时机，不给法律意见。

## 用神

| 爻 | 在纠纷里 |
|---|---|
| 世 | 自己一方 |
| 应 | 对方 |
| 官鬼 | 官府、法官、裁决的那一关；也是压在身上的这件事 |
| 父母 | 诉状、证据、合同、文书 |
| 子孙 | 解神：和解、撤诉、事情消散（子孙克官鬼） |
| 兄弟 | 破财、费用 |

## 看点

- 世旺应衰、世克应：自己占上风；反之对方占上风。
- 官鬼生世：裁决向着自己；官鬼克世：于己不利。
- 子孙发动：有和解、撤的可能。
- 父母旺而生世：证据、文书对自己有利。
- 六冲：易散、易了结；六合：缠绵、难脱身。
