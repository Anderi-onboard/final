A 和 B 是**断法**:程序拿条件去求值,得出「这条生克成不成立」「什么时候应验」。

C 全是**象**,一条断法都没有。

- 「三爻为腰」不决定任何事,它告诉你**往哪儿看**。
- 「羊刃」也不决定任何事 —— CLAUDE.md §6 写着:
  **「神煞尤其要小心:它本来就是辅助,不上卦几乎不承重」「真要承重,得靠用神旺衰生克(不能靠神煞)」。**

所以 C 的产物进 `assets/xiangshu/lei-xiang.json`(万物类象库),**不进断法库、不进裁决梯**。
它没有 `触发`,也没有 `判` —— 那两格是给会改变结论的东西用的,而象不改变结论。

⚠️ 这一条要写死在提示词里,否则 Gemini 一定会写出「羊刃主凶伤」这种句子,
而模型拿到之后会把它当判据用。**一个不承重的东西写成了判据,比没有它更糟** ——
它会在盘面证据不足时替补上来,而那正是这套架构要挡的事。

## 【说明】D 里有一条会翻转结论,而这不违反「现实只能定尺度」

之前定过一条:**现实类信息只能定尺度,不能翻方向。** 盘说弱,现实说有多弱,
但现实不能把「弱」说成「强」。

DOM-ILL 那条铁律看起来正好在犯这个:

> **近病逢空逢冲即愈,久病逢空逢冲必死。**

同一个盘面事实(用神旬空、被日冲),近病断愈、久病断死 —— **方向反了**。
而「近病 / 久病」盘上一个字都读不出来,只能从他的话里来。

这不是例外,是我之前那条规矩说得不够细。要分成两件事:

| | 是什么 | 能不能翻方向 |
|---|---|---|
| **现实尺度** | 盘说弱,现实告诉你有多弱 | **不能** |
| **现实分支** | 现实告诉你**该用哪一条断法读这个盘** | 能 —— 因为翻的是规则,不是盘 |

近病/久病是**现实分支**:它不是覆盖了盘的结论,它是在两条不同的断法之间选了一条。
盘面事实自始至终没变过。

⚠️ 所以现实分支类的条目**必须写出它需要问什么**(`问` 这一格)。
问不出来的时候,正确的做法是**说不知道**,不是挑一条看着顺的。
一条需要输入而没拿到输入就跑了的断法,输出的是一个**看起来完整的答案**,
而那是这套架构最怕的东西。

## 三格的分工(这是这个库的核心,别搞混)

⚠️ 象和类必须分开。「文书」是类别不是实例 —— 读的人看到「文书」会自己脑补成
「证书」然后就停了。所以库里把两层拆开:点词看它出自哪个象,点象看它实际是什么。

⚠️ acts 是**动词**,不是形容词。「热闹起来」「顺水推舟」是动作;
「吉利的」「凶险的」是判断,不许写。

## kind 怎么填

  六个爻位     "linepos"     （新类别)
  十二个神煞   "shensha"     （新类别)

⚠️ 爻位**不要**填成 "position"。库里的 世爻/应爻 是 "position",但那两个是
**角色**(谁),初爻到六爻是**位置**(哪儿) —— 前端把 position 当「会做动作的东西」
在解读里列出来,六个爻位混进去就是六个不会做动作的东西在那儿列动作。

## en 那一半必须真的写

库是双语的,38 个已有符号每一项都有英文。**不要留空、不要写拼音、不要机翻腔。**
英文是给用英文提问的人看的解读用的,写成「Yang Blade」这种直译没有用 ——

## 「类」这一格 —— 这批独有,而且是这批最要紧的一格

**理论类**:触发条件全部读得出盘。比如「官鬼旺相」——盘上就有。

**现实类**:触发条件里有一样东西**盘上一个字都读不出来**,只能从提问人的话里来。
比如疾病那条铁律:

  近病逢空逢冲即愈,久病逢空逢冲必死。

同一个盘面事实(用神旬空、被日冲),近病断愈、久病断死,**方向正好相反**。
而「近病 / 久病」盘上读不出来。

⚠️ 这不是「现实推翻了盘」。盘面事实自始至终没变;变的是**用哪一条断法去读它**。
所以现实类条目必须写 `问`:开跑之前要先问清什么。

  "类": "现实",
  "问": "这病是新起的还是拖了很久的(近病 / 久病)"

问不出来的时候正确的做法是说不知道,不是挑一条看着顺的。

判断一条是不是现实类,就问一句:**这个条件,光看盘能不能确定?**
不能就是现实类,然后把「要问什么」写进 `问`。

买货还是卖货、是自己占还是替人占、是初婚还是再婚、走的是水路还是陆路 ——
这些都是现实类。

## 触发:条件对象四种写法(和批次 A 同一套)

1. { "字段": "<状态字段名>", "值": true }
   { "字段": "旺衰", "值": ["旺","相"] }
2. { "对": "日辰"|"月建"|"太岁"|"时辰", "关系": "<时钟关系名>" }
3. { "对爻": "用神"|"元神"|"忌神"|"世爻"|"应爻"|"任一动爻", "关系": "<爻爻关系名>" }
4. { "变爻": "<变爻关系名>" }

字段名只有这些,不许发明:

  状态字段:旬空 真空 假空 月破 真破 假破 暗动 日破 日墓 月墓
            动化入墓 动化空 世爻 应爻 发动 旺衰(旺/相/休/囚/死)
  时钟关系:临 冲 合 害 刑 受生 受克 生出 克出 比和 入墓
  爻爻关系:生 克 比和 冲 合 害 刑
  变爻关系:回头生 回头克 回头冲 回头合 化进神 化退神 化入墓 化空 化绝 化鬼

这些不是新字段,是六亲。写六亲名就行:

  { "对爻": "子孙", "关系": "克" }

六亲只有五个:父母 兄弟 子孙 妻财 官鬼。

表达不了的时候写「缺」,**不要发明字段名**:

「缺」是我要的第二份产出:哪些条今天能接上,哪些条得先给引擎加东西。

## 「断」这一格

  否决  这条一成立,事就断定不成,不再往下算(《增删卜易》所谓专章否决)
  成立  这条一成立,事就断定成
  加权  既不否决也不断成,只是往一边加分量

⚠️ **否决要谨慎。** 原文说「绝无……可能」「必不能……」这种绝对话的才算否决;
说「难」「不利」「恐有」的是加权。**判据是原文的语气强度,不是你觉得这条有多重要。**
